# ADR-0049: Канонический контейнер HarnessBundle

Статус: принято.

## Контекст

Контракт уже требовал от сборщика одинаковых байтов, структуру с `bundle.json`,
паспортом сетапа, двумя отчётами, файлами и подтверждениями, а provider protocol
объявлял формат `ai-stp-bundle/1`. Реализация при этом сохраняла только хэши и
размеры исходных файлов. Содержимое отбрасывалось, паспорт и отдельные отчёты в
пакет не попадали, а cross-platform oracle сравнивал только JSON-манифест. Такой
результат нельзя передать провайдеру и он не доказывает `REQ-607` и `REQ-625`.

Каталог без контейнера не имеет единой последовательности байтов. Обычный ZIP или
tar, созданный с настройками хоста, несёт время, порядок, сжатие и метаданные ОС,
поэтому одинаковое дерево может получить разные байты на Linux и macOS.

## Решение

`ai-stp-bundle/1` является ZIP-контейнером без сжатия. Порядок членов фиксирован:

```text
bundle.json
setup-passport.json
composition-report.json
conversion-report.json
files/
files/<managed path>...
attestations/
```

Управляемые файлы следуют в каноническом порядке манифеста. Для каждого ZIP-члена
фиксируются дата `1980-01-01T00:00:00`, Unix creator, пустые extra/comment и режим;
содержимое JSON сериализуется по RFC 8785. Сжатие не применяется, поэтому версия
компрессора не влияет на результат. `files/` и `attestations/` присутствуют даже
когда пусты.

У пакета две идентичности:

- `bundle_digest` — доменно разделённый хэш канонического `bundle.json` без самого
  поля `bundle_digest`; он связывает паспорт, отчёты и манифест файлов без
  самоссылки;
- `artifact_digest` — обычный SHA-256 точных ZIP-байтов, которые получает provider.

`bundle.json` содержит `bundle_digest`. Consumer возвращает обе идентичности и
размер контейнера. Provider сначала проверяет `artifact_digest` точных переданных
байтов, затем безопасно разбирает контейнер и независимо пересчитывает логическую
идентичность и каждый член. Совпадение одной идентичности не заменяет вторую.

Паспорт берётся из подтверждённой `SetupVersion`, а не из project ID или снимка
предложения. Неподтверждённое предложение пакета не имеет: без `SetupVersion` нет
нормативной идентичности установки по `ADR-0012` и `ADR-0027`.

Размерный предел относится к готовому контейнеру, включая JSON, ZIP-таблицу и
служебные каталоги. Превышение блокирует весь пакет; частичный архив не возвращается.

## Совместимость

Старые локальные ответы `select bundle`, содержавшие только метаданные, не являются
опубликованными артефактами и не мигрируются. Provider release обязан явно объявить
`ai-stp-bundle/1` и пройти literal golden oracle. Любое изменение порядка, ZIP-
метаданных, имён обязательных членов или алгоритма идентичности создаёт новый формат,
а не расширяет v1 молча.

## Последствия

Сборщик действительно создаёт переносимые байты и может доказать отличие изменения
контента, паспорта, отчёта и контейнера. Цена — хранение полного пакета в памяти на
этапе сборки; она ограничена текущим пределом 64 MiB. Привязка этих байтов к
provider plan/apply является отдельным следующим изменением consumer lifecycle и не
может снова подменяться digest плана.

## Условия пересмотра

Решение пересматривается при необходимости потоковых пакетов больше текущего лимита
или при появлении стандартного подписанного контейнера с теми же детерминированными
и безопасными свойствами.
