# ADR-0010: Отделить публичный профиль от паспорта

Принято 2026-08-03. Заменено `ADR-0023-public-profile-as-authored-object.md`: разделение сохраняется, но публичный профиль перестал быть проекцией выбранных полей паспорта и стал отдельно заполняемым объектом. Читать здесь только контекст исходного выбора.

## Контекст

Паспорт разработчика содержит окружение, установленные инструменты, привычки и историю выбора — данные, которые пользователь не имеет причин публиковать. При этом каталогу нужна авторская идентичность у опубликованных объектов. Публикация объекта и публичность автора — разные решения, и их нельзя связывать неявно.

## Решение

Developer Passport остаётся private canonical object. Публичность реализуется отдельной projection, содержащей только явно выбранные пользователем поля.

## Последствия

Схема получает два отдельных объекта, а не флаг публичности внутри паспорта. Проекция наполняется только явно выбранными полями. Синхронизация, публикация компонента и выдача права другому аккаунту не меняют публичность паспорта. Отрицательный тест на утечку приватных полей в публичную проекцию обязателен.
