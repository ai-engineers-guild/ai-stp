# Публичный профиль

Владелец решения — `ADR-0023` и `ADR-0069`; владелец требований — `SPEC-028`
(ранее `SPEC-003` / `SPEC-013` для отделения от паспорта). Публичный профиль не
является паспортом и не входит в перечень `kind` из `passport-envelope.md`.

## Минимальная форма опубликованной ревизии

```yaml
schema_version: 1
kind: public_profile
account_id: "account_01JQZK7B8N4M6P2R9T5V0X3Y7Z"
display_name: "Danil"
bio: "Строю агентные системы."
links:
  - label: "GitHub"
    url: "https://github.com/rldyourmnd"
avatar_asset_id: null
content_digest: "sha256:…"
```

Обязательны `schema_version`, `kind` и `account_id`. Содержательные поля
необязательны: профиль без заполненных полей означает отсутствие публичного
профиля, а не пустую карточку в каталоге.

## Поля ревизии (закрытый перечень)

| Поле | Ограничение | Смысл |
|---|---|---|
| `display_name` | 1–80 символов UTF-8, если задано | Отображаемое имя |
| `bio` | 0–1500 символов; limited Markdown (списки, заголовки, таблицы, bold/code/links), без HTML-тегов и `javascript:`/`data:` URI | Короткое описание |
| `links` | 0–8 элементов; `label` 1–60; `url` нормализованный HTTPS, уникальные | Внешние ссылки |
| `avatar_asset_id` | id обработанного asset или отсутствует | Связь с AvatarAsset |
| `content_digest` | canonical digest ревизии | Идентичность снимка |

## Lifecycle

- `ProfileDraft` — последняя неопубликованная ревизия владельца.
- Одна published revision на account; publish атомарно заменяет предыдущую.
- Сохранение draft не меняет public projection.
- Preview владельца использует ту же allowlist-проекцию, что public route, но
  доступен только владельцу и не является анонимным URL.
- Owner route дополнительно возвращает `editable`: канонический источник полей
  редактора с `source`, `base_revision_id` и `base_content_digest`. Источником
  служит draft, если он существует, иначе published revision, иначе пустая форма.
  Это не меняет публичную проекцию и позволяет клиенту отбрасывать локальное
  несохранённое состояние, если серверная ревизия уже изменилась.

## Avatar

- Источники: upload (`image/jpeg`, `image/png`, `image/webp`, ≤ 5 MiB) или
  linked OAuth identity (GitHub/Google), уже прочитанная сервером.
- Клиент не передаёт произвольный remote URL.
- Provider URL никогда не становится public avatar URL: сервер нормализует,
  снимает EXIF, кладёт processed asset в object storage, отдаёт безопасный URL.
- Состояния asset: `processing`, `ready`, `rejected`, `deleted`.

## Публичная проекция (allowlist)

Публичный маршрут отдаёт только: `account_id`, текущий `author_verified`,
опубликованные `display_name`, `bio`, `links`, безопасный адрес avatar (если asset в состоянии `ready`),
список опубликованных объектов. Не отдаёт: адрес почты, связанную identity,
черновик, ключ объекта, исходный URL источника media, состояние проверки media.

## Что запрещено

Профиль не содержит значения окружения, инструменты, пути, историю решений и
поля паспорта разработчика. Изменение паспорта не меняет профиль.

## Отношение к verified

`author_verified` хранится отдельно (`SPEC-007`) и не выводится из заполненности
профиля. Публичная проекция читает актуальное значение при каждом запросе, поэтому
выдача или отзыв не требует перепубликации профиля.
