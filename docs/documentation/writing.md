# Правила текста

- Документация на русском.
- Технический идентификатор сохраняется в исходном виде.
- Один термин используется для одного понятия.
- Факт, решение, рекомендация и неизвестное состояние не смешиваются.
- Документ описывает действующее состояние, а не пожелание, если явно не назван целевым.
- Ссылка объясняет, зачем открывать целевой файл.
- Команда приводится только если она существует или явно помечена как будущая.
- Обязательное правило должно по возможности иметь автоматическую проверку.
- Не дублировать большой нормативный блок: ссылаться на его канонического владельца.
