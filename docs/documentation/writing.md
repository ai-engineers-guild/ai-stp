# Writing Rules

- Documentation is written in English.
- A technical identifier is preserved in its original form.
- One term is used for one concept.
- Facts, decisions, recommendations, and unknown states are not conflated.
- A document describes the current state rather than an aspiration unless explicitly identified as a target state.
- A link explains why the target file should be opened.
- A command is shown only if it exists or is explicitly marked as future work.
- A mandatory rule should have an automated check whenever possible.
- Do not duplicate a large normative block; link to its canonical owner.
