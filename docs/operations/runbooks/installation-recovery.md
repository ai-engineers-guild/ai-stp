# Восстановление установки

1. Остановить новые изменения target.
2. Прочитать журнал операции и результат провайдера.
3. Различить применённое без проверки, частичное и неуспешное состояния.
4. Проверить текущий digest target и ссылку резервной копии.
5. Не повторять применение вслепую.
6. Выполнить проверку состояния провайдера.
7. При целостном новом target повторить проверку результата.
8. Иначе построить план восстановления точной резервной копии.
9. Проверить восстановленное состояние и активный указатель.
10. Сохранить остаточную неопределённость.
