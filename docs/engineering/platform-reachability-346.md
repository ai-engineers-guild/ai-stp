# Reachability gate: план реализации #346

Статус: выполнено. `#346` закрыт слиянием `#366` 2026-08-16, и ниже — план,
по которому это делалось, а не оставшаяся работа. Запись сохраняется как
нормативная трассировка требований к коду, который уже в основной линии.

## Нормативная база

Гейт описан в `docs/engineering/quality-gates.md`. Отдельный ADR не нужен:
это инженерная проверка, не смена публичного контракта.

## Владельцы

- проверка: `tests/contract/test_reachability.py`;
- определения: `apps/cli`, `apps/api`, `apps/platform`, `apps/worker`;
- ссылки: первопартийный исходник (`apps/*`, `packages/*`), не `tests/`.

## Реализация

1. Собрать публичные функции уровня модуля из четырёх приложений.
2. Считать вызовами `Name` и `module.name` из `apps/` и `packages/`, без
   каталогов тестов.
3. Функцию с декоратором маршрута FastAPI/Starlette считать достигнутой.
4. Каждую находку подключить, удалить или внести в `EXEMPT` с причиной,
   которая называет существующий объект.
5. CLI-проверки `next_actions` и кодов ошибок остаются только на `apps/cli`.

## Проверка

`uv run --locked pytest tests/contract/test_reachability.py -q`.
Генераторы не нужны.
