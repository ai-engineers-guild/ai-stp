### Продукт

Поддерживаются пять харнессов: Claude Code и Codex в основной поддержке, Pi, OpenCode и Grok Build в бете, плюс ограниченный `undefined` для неизвестного.

Лицензия AGPL-3.0-or-later. Команда из двух человек: `rldyourmnd` — весь CLI и локальный контур, `letya999` — платформа и веб.

### Принятые решения, которые стоит оспорить по существу

Каждое — отступление от текста задачи, сделанное осознанно и записанное ADR. Оценивай основание, а не сам факт отступления.

1. Click вместо Typer. Машинная справка порождается из реестра команд, поэтому функций с аннотациями типов не существует и то, ради чего выбирался Typer, неприменимо. Измерено дополнительно: Typer 0.27 тянет Rich в дерево CLI, чей машинный вывод запрещает управляющие последовательности, и везёт вендоренный шим Click, несовместимый с установленной версией — обычная опция Click внутри группы Typer падает.
2. Нет команды записи конфигурации. Контракт делает третий ярус приоритета переопределением на один вызов, а не записью; ни одно требование не просит писателя конфигурации. Файл правит пользователь.
3. Стандартный модуль SQLite вместо Alembic. Измерено: Alembic приходит только вместе с SQLAlchemy — 510 мс на импорт и 14 МБ против 2 мс у стандартной библиотеки, ради хранилища из пяти таблиц.
4. Локальный владелец до входа. Конверт паспорта требует идентификатор владельца вида `account_…`, а выдаёт их сервер; автономный контур обязан создавать паспорта раньше. Выдаётся локальный идентификатор, вход переносит владение обычной ревизией.
5. Вход двумя командами вместо одной. CLI не блокируется в ожидании человека: это подвисло бы в CI и в контейнере. Кроме того, две фазы отвечают разными полезными нагрузками, а команда объявляет ровно одну схему результата.
6. Двухъярусное хранилище секретов: системное хранилище, когда оно действительно есть, иначе файл с правами владельца; использованный ярус всегда назван в ответе. Ярус переменной окружения запрещён требованием о непередаче секрета через окружение. Backend системного хранилища принимается только из закрытого перечня: измерено, что с установленным пакетом альтернативных backend-ов запись молча проходит и секрет ложится на диск в base64, пока библиотека рапортует об успехе.
