# hook

![Component type: hook](/content/illustrations/kind-hook.jpg)

Проверьте событие, обработчик, исполняемый файл и аргументы. Hook может запуститься при первом подходящем событии. Сверьте событие и цель с планом.

Перед авторингом прочитайте схему входных данных:

```sh
ai-stp task input-schema --intent author --json
```
