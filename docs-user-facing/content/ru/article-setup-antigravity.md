# Antigravity CLI

![Профиль Antigravity CLI](/content/illustrations/setup-antigravity.jpg)

Используйте ID харнесса `antigravity`. Каталог обнаружения включает `antigravity-cli/settings.json`.
Проверьте точную версию сетапа и корни в плане `configuration native`.
План перечисляет изменения файлов для выбранных корней.

Исполняемым файлом харнесса управляет пользователь или поставщик. Если
план требует передачи сессии, завершите исходный процесс, примените план,
перезапустите харнесс и подтвердите новый процесс.

[Процедура установки](https://docs.nddev.asia/quickstart/agent/)
