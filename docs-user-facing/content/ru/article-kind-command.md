# command

![Component type: command](/content/illustrations/kind-command.jpg)

Используйте command для действия, которое пользователь вызывает по имени. Проверьте аргументы и область применения. Команды самого ai-stp перечисляет справка CLI.

Перед авторингом прочитайте схему входных данных:

```sh
ai-stp task input-schema --intent author --json
```

Опубликованная версия компонента неизменяема. Перед добавлением в сетап
проверьте точную версию и результаты проверок.
