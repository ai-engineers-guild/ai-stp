# MiMoCode

![Профиль MiMoCode](/content/illustrations/nddev-builder.jpg)

Для MiMoCode нет нативного профиля ai-stp. Поддерживаемые харнессы
вашего CLI указаны в `data.native_configuration.harnesses` ответа
`ai-stp capabilities --json`.
