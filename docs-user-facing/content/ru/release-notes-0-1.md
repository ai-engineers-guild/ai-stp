`ai-stp-cli` `0.0.15` — текущая публичная линейка. Команда — `ai-stp`. Устанавливайте её через `uv tool install ai-stp-cli`, затем запускайте `ai-stp doctor --json`. Эта заметка для операторов, которым нужна честная карта того, что линейка будет и не будет делать, а не список web feature flags.

## Что готово в этой линейке

Можно установить CLI, создать устройство и паспорт разработчика и читать публичный каталог без аккаунта. Можно обнаруживать нативные компоненты в поддерживаемых раскладках харнессов, принимать их локально и компилировать сетап из точных pin. Можно запросить план установки, утвердить его по digest и применить через провайдера харнесса, с резервной копией и статусом на другой стороне.

Можно войти, опубликовать неизменяемую `X.Y` из публичного коммита GitHub, синхронизировать приватные ревизии между своими устройствами через `sync pull`, выдать другому аккаунту доступ к major-линии и отправить закрытый отчёт. Сайт показывает тот же публичный каталог и аккаунт. Он не применяет сетап.

Паспорта несут происхождение, совместимость, ограничения и результаты проверок в виде, которое читают и человек, и агент. `author_verified` и `component_verified` остаются независимыми. Механическая совместимость и политика доверия выполняются до рассуждений агента. ai_stp не вызывает API модели и не требует ключа модели.

## Харнессы

| Харнесс | Статус на 0.0.15 |
| --- | --- |
| Claude Code | основной |
| Codex | основной |
| Grok Build | основной |
| Pi | бета |
| OpenCode | бета |
| Cursor | бета |
| Antigravity | бета |
| неизвестный | `undefined` — без автоматической установки |

Основной означает, что производственный путь сначала рассчитан на него: паспорта, граф, план провайдера, apply. Бета означает, что продукт уже отличает харнесс и умеет работать с его объектами, но части пути провайдера или нативной поверхности всё ещё просят больше подтверждений. Если нужен самый короткий проверенный путь, начинайте с основного харнесса.

## Чем MVP всё ещё не является

Это не командный продукт. Сетап принадлежит одному аккаунту. Двое людей не делят один рабочий сетап проекта. Выдачи доступа делят объекты; они не создают общую сессию правки.

Это не маршрутизатор моделей. Внутри продукта нет вызова интерфейса модели.

Это не обещание безопасности. Подтверждённое происхождение и текущие проверки снижают известный риск. Они не переносят ответственность за чтение того, что `mcp`, `hook` или `plugin` сделают после записи нативного состояния провайдером.

Это не тихий установщик обновлений. Точные pin `X.Y` остаются точными. Отказы остаются отказами. Бета-харнесс помечен как бета.

Если машинная справка установленного CLI расходится с запомненным флагом, следуйте CLI.

## Как отличить эту линейку от web-профиля

Версия пакета `0.0.15` — линейка CLI и каталога, которую описывает эта заметка. Это не профиль деплоя сайта и не ревизия темы MkDocs. `ai-stp version --json` печатает `cli_version` бинарника в `PATH`. `doctor --json` сообщает, может ли эта установка работать локально, до привязки аккаунта.

Публичный каталог, страницы издателей и этот хаб материалов читаются без входа. Аккаунт, устройства, объекты, выдачи и жалобы требуют OAuth и онбординга. Staff URL — не пользовательская поверхность.

## После установки

```bash
uv tool install ai-stp-cli
ai-stp doctor --json
ai-stp version --json
ai-stp capabilities --json
```

`doctor` говорит, может ли локальная установка работать до привязки аккаунта. `capabilities` — какие харнессы знает этот бинарник. Ни то ни другое не ставит сетап. 142 команды живут в реестре CLI и сгруппированы на карте справочного центра. Копируйте из `ai-stp help --agent --json`, не из памяти.

Эта заметка не датирует следующий релиз. Она не документирует staff URL. Она не перечисляет feature flags сайта. Если публичный каталог и эта заметка расходятся по статусу харнесса, карточка каталога — живой объект, а заметка — описание линейки: подайте жалобу на дайджест, не выдумывайте третий статус. Исполняемый файл — `ai-stp`. Дистрибутив — `ai-stp-cli`. Флаги в эту заметку не копируются: они едут с установленным CLI.
