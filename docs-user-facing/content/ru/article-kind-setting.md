# setting

![Component type: setting](/content/illustrations/kind-setting.jpg)

Используйте setting для значений конфигурации. Проверьте ключи и изменения файлов в плане для нужной области. Учётные данные храните отдельно.

Перед авторингом прочитайте схему входных данных:

```sh
ai-stp task input-schema --intent author --json
```

Опубликованная версия компонента неизменяема. Перед добавлением в сетап
проверьте точную версию и результаты проверок.
