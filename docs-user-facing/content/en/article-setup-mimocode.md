# MiMoCode

![(MiMoCode) profile](/content/illustrations/nddev-builder.jpg)

MiMoCode has no native configuration profile in ai-stp. Check the
`data.native_configuration.harnesses` list from `ai-stp capabilities --json`
for the harnesses available in your installed CLI.

[CLI reference](https://docs.nddev.asia/en/cli/)
