# Grok Build

![(Grok Build) profile](/content/illustrations/setup-grok-build.jpg)

Use harness ID `grok-build`. The discovery catalog includes `AGENTS.md` and `config.toml`.
Review the exact setup version and target roots in a `configuration native`
plan. The plan lists the file changes allowed for those roots.

The user or vendor manages the harness executable. If the plan requires
handoff, close the original session, apply the reviewed plan, restart and
confirm the new process.

[Setup procedure](https://docs.nddev.asia/en/quickstart/agent/)
