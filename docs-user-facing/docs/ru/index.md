# ai-stp

ai-stp создаёт, проверяет, выбирает и устанавливает конфигурации ИИ-харнессов.
Движок — CLI на Rust; веб отвечает за аккаунт и публичный каталог. Сетап принадлежит
одному харнессу и фиксирует точные неизменяемые версии компонентов.

[Установите CLI](quickstart/human.md), затем используйте
[процесс для агента](quickstart/agent.md). [Справка CLI](cli/index.md) описывает
команды и состояние; [каталог](catalog/index.md) и [доверие](trust-and-safety/index.md)
объясняют результаты проверок.

CI проверяет Linux x86-64, macOS Apple Silicon и Windows x86-64. Изолированная
установка сетапов и передача активной сессии пока доступны на Linux. Харнессом
управляет пользователь или поставщик. CLI не требует ключа модели, не отправляет
телеметрию и не обновляется автоматически.
