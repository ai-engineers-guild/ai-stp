# ai-stp

ai-stp создаёт и устанавливает конфигурации ИИ-харнессов. Сетап закрепляет
неизменяемые версии компонентов для одного харнесса. CLI и Desktop используют
один нативный движок. Веб предоставляет аккаунты и публичный каталог.

Начните с [установки](quickstart/human.md) или [инструкции для агента](quickstart/agent.md).
Команды и состояние описаны в [справке CLI](cli/index.md), проверки и восстановление —
в разделе [«Доверие и безопасность»](trust-and-safety/index.md).

CI проверяет Linux x86-64, macOS Apple Silicon и Windows x86-64. Возможности
настройки и передачи сессии вашего CLI указаны в `data.native_configuration`
ответа `ai-stp capabilities --json`.
