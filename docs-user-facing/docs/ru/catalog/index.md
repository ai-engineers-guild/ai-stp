# Каталог

Публичные объекты доступны без аккаунта. Вход через веб нужен для закрытых объектов,
публикации, предоставления доступа и синхронизации. CLI выполняет выбор, сборку
и установку; веб показывает объекты и результаты проверок.

Сетап конфигурирует один харнесс и ссылается на точные версии компонентов.
Перед применением проверьте происхождение, лицензию, совместимость и актуальные
доказательства. Проверка автора относится к личности и отделена от проверки байтов.
Успешное чтение каталога не означает установку.

Перед установкой укажите точную версию сетапа и корни по
[инструкции для агента](../quickstart/agent.md).
