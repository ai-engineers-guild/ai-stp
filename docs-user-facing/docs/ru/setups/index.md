# Сетапы

Setup — полная конфигурация одного harness: точные версии компонентов,
нативные проекции и ограничения совместимости. Сохранённые версии неизменяемы;
изменение содержимого создаёт новые версионированные данные.

```bash
ai-stp help --path setup --json
ai-stp help --path configuration --json
```

Сборщик проверяет граф и готовит нативные пакеты. Компоненты установки из
существующих репозиториев setup-систем входят в ai-stp; только выбранный
провайдер записывает итоговое состояние harness. Все корни подготавливаются
до записи. Прерванная операция продолжается по журналу и точным результатам.
Отдельной системы backup/rollback нет.

Исполняемым файлом harness управляет пользователь. Активный агент не меняет
свою конфигурацию частично: нужны подготовленная передача управления и перезапуск.
