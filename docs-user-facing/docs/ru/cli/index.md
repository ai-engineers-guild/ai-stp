# CLI на Rust

Команды и параметры определяет реестр исполняемого файла:

```sh
ai-stp help --agent --json
ai-stp task intents --json
ai-stp task input-schema --intent install --json
```

`help --path <command> --json` показывает выбранную группу. Задачи охватывают
создание объектов и установку; аккаунт, синхронизация и публикация имеют прямые
команды. Не восстанавливайте команды из старых записей сессий.

Машинный режим возвращает один JSON-конверт. Проверяйте состояние и квитанции:
план ещё не означает применение, а сохранённый статус аккаунта не доказывает
действующую сетевую сессию. Изменения привязаны к точным данным и дайджесту.
После прерывания продолжайте исходную допущенную операцию; сначала прочитайте
текущую ревизию задачи.

Явный YAML-файл поддерживает `catalog.enabled`, `catalog.url`, `sync.enabled`.
Передайте его через `--config`; синхронизация по умолчанию выключена. Учётные данные
находятся в выбранном хранилище. Каталог состояния выбирается через `--state-dir`,
`AI_STP_STATE_DIR` или каталог данных XDG. Это данные пользователя, а не кэш.

[Нативное руководство](https://github.com/ai-engineers-guild/ai-stp/blob/main/apps/cli-v2/README.md)
описывает установку, перенос состояния и ограничения платформ.
[Работа агента](../quickstart/agent.md) описывает выполнение задач.
