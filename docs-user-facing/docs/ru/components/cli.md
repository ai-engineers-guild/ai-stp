# `cli`

`cli` — отдельная программа с process entry point. Агент обнаруживает,
регистрирует, публикует, устанавливает и вызывает её как процесс.

`cli` отвечает на вопрос: **какой общий исполняемый файл можно запустить?**

Это не «какую проверяемую операцию можно вызвать по имени?»
([`command`](command.md)). Slash-команда — именованный вызов внутри харнесса.
`cli` — процесс. Это также не сам исполняемый файл `ai-stp` — он живёт в
[CLI](../cli/index.md).

!!! warning "Вид `cli` — не slash-команда"

    | Объект | Где живёт | В сетапе? |
    | --- | --- | --- |
    | Вид `cli` (эта страница) | один общий исполняемый артефакт | да |
    | Вид `command` | slash/prompt поверхность харнесса | да |
    | Группы CLI `ai-stp …` | [карта CLI](../cli/commands.md) | нет |

    Не копируйте один бинарник в семь layout харнессов. Scaffold — portable.
    Интеграция — запуск процесса, не семь нативных копий.

## Соседи

| Вид | Главное отличие |
| --- | --- |
| `command` | команда вызывается по имени внутри харнесса; `cli` — процесс |
| `hook` | hook стартует на событии жизненного цикла; `cli` — когда его исполняют |
| `mcp` | MCP говорит протоколом; `cli` — обычная программа |
| `skill` | skill — процедура, которую харнесс подключает; `cli` — исполняемый файл |
| `plugin` | plugin расширяет сам харнесс; `cli` — общий инструмент |
| `setting` | setting держит параметры; `cli` держит программу |

Выбирайте `cli`, когда объект — отдельный исполняемый файл. Выбирайте
`command`, когда работу запускают slash-именем.

## Рекомендуемая структура пакета

`cli` исполняемый. `--language` — одно из `python`, `typescript`,
`javascript`, `rust`, `go` или `dart-flutter`. `--harness` — `portable`.

```text
review-kit/                        # component-scaffold/6
├── .ai-stp-template.json
├── .gitignore
├── README.md
├── component-passport.json
├── eval-profile.json
└── source/
    └── src/main.py
```

## Красные флаги

- Scaffold `--type command` для процесса, который не является slash-командой.
- Конкретный harness variant, из-за которого один бинарник копируется семь раз.
- Считать сам `ai-stp` каталожным компонентом `cli`.
