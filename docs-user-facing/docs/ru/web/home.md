# Главная

Лендинг — публичная входная дверь. Он говорит, что такое `ai_stp`,
предлагает каталог и копирует единственную поддерживаемую команду
установки. Он не запускает эту команду, не создаёт аккаунт и не пишет
харнесс.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human | `/{locale}/` | всем |
| Machine | `/{locale}/ai/` | всем |

`{locale}` — это `en` или `ru`. Одни и те же факты на обеих проекциях.
Вошедшие посетители всё равно видят Главную; кнопка Войти для них
скрыта (`SignedOutOnly`). Отдельного лендинга для аутентифицированной
сессии нет.

## Для чего этот экран

Главная нужна, чтобы:

- прочитать продуктовую фразу: реестр сетапов, а не свалка скиллов;
- скопировать `uv tool install ai-stp-cli` буквально;
- открыть каталог;
- открыть Вход, если сессии нет.

Главная **не**:

- собирает сетап;
- определяет ваш харнесс;
- хранит ключ модели (продукту он никогда не нужен);
- сама запускает OAuth (Вход — отдельная страница);
- показывает персональные объекты.

Превью рабочего процесса за героем декоративное. Это не живой
статус вашей машины.

## Что на экране

Герой на весь viewport, тёмный даже когда остальной сайт светлый.

| Элемент | Подпись | Что делает |
| --- | --- | --- |
| Заголовок | Реестр ИИ-сетапов, а не просто каталог скиллов | продуктовое утверждение |
| Подзаголовок | Находить, проверять, ставить и зарабатывать на ИИ-компонентах. | короткий питч |
| Основная кнопка | Открыть каталог | ведёт на `/{locale}/catalog` |
| Вторичная кнопка | Войти | ведёт на `/{locale}/login`; скрыта после входа |
| Панель установки | Установка CLI | копирует `uv tool install ai-stp-cli` |
| Копирование | Копировать / Скопировано | пишет эту строку в буфер |
| Предварительные требования | `uv`, `python>=3.12` | чего ожидает команда |

Подсказка установки говорит: выполните команду как есть; не собирайте
её сами. Исполняемый файл — `ai-stp`. Дистрибутив на PyPI —
`ai-stp-cli`. `uv tool install ai-stp` ставит другой пакет, который
этот проект не публикует.

Переключатель Human / Machine остаётся внизу окна. Machine-Главная —
короткий Markdown: заголовок, подзаголовок, ссылка на каталог, ссылка
на Документацию, заголовок установки и fenced-копия той же команды.
Документация там указывает на `AI_STP_USER_DOCS_URL`, когда presenter
его получил; это не страница OpenAPI API.

Шапка и подвал — общая оболочка, описанная в [Веб](index.md).
**Документация** в шапке — внешний хост MkDocs.

Клавиатура:

| Клавиша | Действие |
| --- | --- |
| `C` | Контакт, когда включён `saas_public_pages` |
| `P` | Аккаунт или Вход |
| `Ctrl`/`Cmd` `K` | поиск каталога, на странице каталога |

## Соответствующие команды CLI

Эти команды есть в реестре работающего CLI. Копируйте их с
`--json`.

```bash
uv tool install ai-stp-cli
ai-stp version --json
ai-stp doctor --json
ai-stp capabilities --json
ai-stp registry search --json
```

`version` сообщает о работающем билде. `doctor` — чтение: он не
создаёт устройство. `capabilities` говорит, с какими поверхностями
этот билд умеет говорить. `registry search` читает публичный каталог
без аккаунта.

После того как инструмент на `PATH`, следующие локальные идентичности
создаются в CLI, не на этой странице:

```bash
ai-stp device init --json
ai-stp passport developer init --json
```

Эти команды описаны в [Устройство](../cli/device.md) и
[Паспорта](../cli/passport.md). Главная их никогда не запускает.

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| Кнопки Войти нет | сессия уже есть | открыть Аккаунт из шапки |
| Копирование ничего не делает | браузер заблокировал буфер | выделите блок `<code>` и скопируйте |
| `ai-stp` не найден после установки | инструменты `uv` не в `PATH` | см. [Диагностику](../troubleshooting/index.md) |
| Кнопка каталога работает, установка нет | Главная только копирует строку | почините `uv` / Python локально |
| Machine-вид выглядит скудным | это проекция | факты совпадают; оболочка — Markdown |
| Контакта нет в шапке | self-hosted профиль | ожидаемо; Каталог всё равно работает |

Сама Главная не даёт 404. Неверный префикс locale даёт 404 оболочке
сайта.

Если API лежит, Главная всё равно рендерится: это статическая
оболочка плюс строка установки. Каталог за «Открыть каталог» может
тогда показать `Сервис временно недоступен`.

## Что происходит после установки

Команда лендинга только ставит `ai-stp` на машину. Сетап по-прежнему
выбирается и применяется в CLI:

```text
копия с Главной → uv tool install ai-stp-cli
                → doctor / capabilities
                → registry search
                → select / install plan
                → provider apply
```

В этой цепочке нет website POST, кроме позднего входа, лайков,
жалоб и confirm публикации.
