# Аккаунт

Аккаунт — страница идентичности после входа: id аккаунта, связанные
идентичности Google и GitHub, ярлыки на публичный профиль и флаги
приватности. Это не страница издателя, которую видят посетители, и не
паспорт разработчика.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human | `/{locale}/account` | после входа, онбординг завершён |
| Machine | `/{locale}/ai/account` | та же сессия |
| Human-приватность | `/{locale}/account/privacy` | после входа |
| Machine-приватность | `/{locale}/ai/account/privacy` | та же сессия |

Нет сессии → вход с `returnTo`. `onboarding_pending` →
[Онбординг](onboarding.md). Меню аккаунта (клавиша `P`) открывает эту
страницу после входа и Вход, когда сессии нет.

Machine-Аккаунт печатает `account_id` и каждую идентичность полями.
Cookie он не раскрывает.

## Для чего этот экран

Аккаунт нужен, чтобы:

- скопировать `account_id` (id издателя на карточках каталога);
- отвязать лишнюю OAuth-идентичность или привязать недостающую;
- открыть редактор публичного профиля;
- открыть флаги приватности и настройки cookies;
- выйти из браузерной сессии.

Аккаунт **не**:

- правит отображаемое имя (это [Профиль](profile.md));
- перечисляет устройства (это [Устройства](devices.md));
- перечисляет свои компоненты (это [Объекты](objects.md));
- удаляет аккаунт с этой страницы;
- пишет харнесс или паспорт.

## Что на экране

| Элемент | Подпись | Эффект |
| --- | --- | --- |
| Идентификатор аккаунта | Идентификатор аккаунта | элемент копирования |
| Публичный профиль | Редактировать профиль | `/{locale}/account/profile` |
| | Посмотреть публичный профиль | `/{locale}/publishers/{account_id}` |
| Способы входа | provider, отображаемое имя, привязан | одна строка на идентичность |
| Отвязать | Отвязать | отказ, если это последняя идентичность |
| Привязать другого провайдера | Войти через Google / GitHub | step-up `/v1/auth/link/{provider}` |
| Приватность | Настройки приватности | `/{locale}/account/privacy` |
| Выйти | Выйти | POST `/api/auth/logout?locale=…` |

Отвязка последней идентичности блокируется:

> Нельзя отвязать последнюю идентичность аккаунта.
> Должна остаться хотя бы одна идентичность, чтобы можно было войти
> снова.

Привязка другого провайдера — **не** слияние. Если эта идентичность
Google или GitHub уже принадлежит другому аккаунту, login/link
возвращает конфликт, и слияния нет.

### Приватность

`/{locale}/account/privacy`:

| Флаг | Подпись | Смысл |
| --- | --- | --- |
| `show_profile_publicly` | Показывать профиль публично | посетители могут видеть богатый профиль |
| `allow_publisher_listing` | Показывать в списке авторов | аккаунт может появиться в списках издателей |

**Сохранить настройки** записывает эти два флага. Они не прячут уже
опубликованные объекты каталога. Они не меняют `author_verified`.

Настройки cookies на той же странице снова открывают баннер согласия:
Необходимые (всегда включены), Аналитика, Маркетинг.

Переключатель Human / Machine сохраняет `/account` vs
`/account/privacy`.

## Соответствующие команды CLI

```bash
ai-stp auth status --json
ai-stp auth logout --json
ai-stp link web --json
ai-stp owner objects --json
```

`auth status` сообщает отношение платформы для **этого CLI-
устройства**, которое может отличаться от cookie браузера.
`auth logout` завершает облачную сессию на сервере и на этом
устройстве, сохраняя локальные данные. Выход в браузере не запускает
`device reset`.

Команды `ai-stp account privacy` нет. Флаги видимости — POST сайта.

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| Редирект на вход | нет или устаревшая сессия | войти |
| Редирект на онбординг | правовые редакции не приняты | [Онбординг](onboarding.md) |
| Отвязка последней заблокирована | одна идентичность должна остаться | сначала привяжите другого провайдера |
| Конфликт привязки | идентичность принадлежит другому | используйте тот аккаунт; слияния нет |
| Не удалось отвязать | отказ API | обновите; проверьте CSRF |
| Публичный профиль 404 | приватность пустая / не опубликовано | опубликуйте из Профиля или игнорируйте |
| Сервис временно недоступен | API лежит | повторите; CLI `auth status` скорее локальный |
| Вышли, но CLI всё ещё аутентифицирован | две сессии | `ai-stp auth logout --json` на устройстве |

Отзыв **текущего** браузерного устройства на странице Устройств тоже
выходит. Это отзыв устройства, не эта кнопка Выйти.

## Идентичности и сессии

Продукт допускает Google и GitHub. Ноль идентичностей на активном
аккаунте невозможен: OAuth создал первую. Две — максимум.

| Вы хотите | Используйте |
| --- | --- |
| Остановить только этот браузер | Выйти на этой странице |
| Остановить этот браузер как облачное устройство | Отозвать текущее на [Устройствах](devices.md) |
| Остановить облачную сессию CLI | `ai-stp auth logout --json` |
| Списать локальную идентичность CLI | `ai-stp device reset --confirm --json` |
| Спрятать био издателя | флаги приватности, затем Сохранить настройки |

`account_id` стабилен. Копируйте его, когда кому-то нужно выдать вам
major-линию ([Доступ](access.md) ID пользователя) или когда вы
подаёте жалобу, называющую издателя. Это не секрет, но и не email.

Machine-Аккаунт только для чтения: id + идентичности. Отвязка и
привязка — human POST.
