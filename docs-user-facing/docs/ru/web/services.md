# Региональные сервисы

Региональные сервисы — рыночный атлас. Вы выбираете страну или внешний
сервис, затем открываете все публичные компоненты и сетапы, которые с
ним связаны. Страница не утверждает, что эти объекты принадлежат
только этому рынку, и ничего не устанавливает.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human index | `/{locale}/services` | всем |
| Machine index | `/{locale}/ai/services` | всем |
| Human service | `/{locale}/services/{canonical_domain}` | всем |
| Machine service | `/{locale}/ai/services/{canonical_domain}` | всем |
| Human country | `/{locale}/countries/{code}` | всем |
| Machine country | `/{locale}/ai/countries/{code}` | всем |

Подпись в шапке — **Региональные сервисы**. В подвале то же в колонке
Product. Атлас может читать кто угодно. Привязка сервиса к своему
объекту — действие владельца на [Объектах](objects.md), не здесь.

Когда `NEXT_PUBLIC_EXTERNAL_CATALOG_ENABLED` равен `false`,
**детальные** страницы сервиса и страны дают 404. Индекс всё ещё может
отрисовать пустой explorer. Это флаг деплоя, не шлюз сессии.

## Зачем этот экран

Атлас нужен, чтобы:

- видеть рынки СНГ как страны;
- фильтровать список сервисов по стране и по имени сервиса;
- открыть карточку сервиса (основной HTTPS URL, страны, связанные объекты);
- перейти в каталог с фильтрами страны или сервиса.

Атлас **не**:

- продаёт внешний продукт;
- помечает компонент как валидный только в этой стране;
- создаёт сервис (это владельцы со страницы объекта);
- запускает Catalog QL (это остаётся в [Каталоге](catalog.md)).

Перечисленные сервисы — связанные, не исключительные. Сетап может
назвать `kaspi.kz` и всё равно быть применим в другом месте.

## Что на экране

### Индекс

Первый экран — сумеречная пластина-обзор, заголовок **Региональные
сервисы** и орбита флагов СНГ. Ниже компактные фильтры:

| Элемент | Подпись | Эффект |
| --- | --- | --- |
| Страны | Все страны / один код | сужает список сервисов |
| Сервисы | Все сервисы / один домен | сужает дальше |
| Счётчик | `N сервис(ов)` | сколько совпало |
| Пусто | Для выбранной комбинации сервисов нет. Сбросьте один из фильтров и попробуйте снова. | сбросьте один фильтр |

Каждый видимый сервис показывает имя, канонический домен и страны.
Действия:

| Действие | Куда |
| --- | --- |
| О сервисе | `/{locale}/services/{canonical_domain}` |
| Открыть в каталоге | каталог с `service_domain` / `country_code` |
| Чип страны | `/{locale}/countries/{code}` |

**Не задано** в фильтрах страны каталога — объекты без списка
стран. Это не страна этого атласа.

Human / Machine сохраняет путь. Machine index — список сервисов и
стран ссылками Markdown и полями.

### Карточка сервиса

| Элемент | Содержимое |
| --- | --- |
| Kicker | Внешний сервис |
| Title | имя сервиса |
| Link | `canonical_domain` → `primary_url` (HTTPS) |
| SEO summary | когда есть профиль |
| Country chips | ISO-коды со ссылками на страницы стран |
| Компоненты и сетапы | связанные публичные объекты |

Ссылки на объекты ведут на
`/{locale}/catalog/{components\|setups}/{stable_id}`. Отсутствующий
объект опускается, а не показывается сломанной карточкой.

### Карточка страны

| Элемент | Содержимое |
| --- | --- |
| Code | ISO-код страны |
| Title | локализованное имя региона |
| Сервисы | сервисы, которые указывают эту страну |
| Компоненты и сетапы | объекты, связанные с этим рынком |

## Совпадающие команды CLI

Команды `ai-stp services` нет. Близнец — поиск каталога:

```bash
ai-stp registry search --json
ai-stp registry show --kind component --id <stable_id> --json
ai-stp registry show --kind setup --id <stable_id> --json
```

Передавайте те же ограничения harness, tag или author, что после
выхода из атласа. Фильтры страны и сервиса — query-ключи сайта
(`country_codes`, `service_domains`), которые уходят в поиск каталога.

Владельцы привязывают сервисы к объекту, опубликованному из CLI, затем
редактором сайта:

```bash
ai-stp owner objects --json
ai-stp owner object show --json
```

Форма **Внешние сервисы** на странице объекта описана в
[Объектах](objects.md).

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| Для выбранной комбинации сервисов нет | оба фильтра слишком узкие | сбросьте страну или сервис |
| Сервис 404 | неизвестный домен или внешний каталог выкл. | вернитесь к индексу |
| Страна 404 | неизвестный код или внешний каталог выкл. | вернитесь к индексу |
| Пустые Компоненты и сетапы | ещё ничего не связано | не выдумывайте объекты |
| Открыть в каталоге пуст | фильтры каталога дали ноль | снимите фильтр; включите experimental |
| Primary URL выглядит ненадёжно | вы ушли с ai_stp | считайте это сторонним сайтом |
| Здесь нельзя добавить сервис | вы не на объекте владельца | опубликуйте в CLI, затем Objects |

Графика атласа — оригинальная топографическая работа. Это не живая
карта деплоев и не счётчик установок.
