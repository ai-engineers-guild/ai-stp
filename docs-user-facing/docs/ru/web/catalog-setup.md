# Карточка сетапа

Карточка сетапа — публичная страница одного сетапа каталога. Сетап —
полная конфигурация одного харнесса: точные пины компонентов, а не
папка текущих файлов. Замена любого пина — новая версия сетапа.

Страница показывает этот граф. Она его не собирает, не обновляет и не
применяет.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human | `/{locale}/catalog/setups/{stable_id}` | всем |
| Machine | `/{locale}/ai/catalog/setups/{stable_id}` | всем |
| Human-версия | `/{locale}/catalog/setups/{stable_id}/versions/{version}` | всем |
| Machine-версия | `/{locale}/ai/catalog/setups/{stable_id}/versions/{version}` | всем |

`{stable_id}` должен быть id сетапа. Id компонента даёт 404.
Неизвестные, заблокированные или неопубликованные сетапы дают 404 без
указания, какой случай.

Публичный сетап может читать кто угодно. Лайк и жалоба требуют
сессии. Редактора презентации для сетапов на сайте нет: правка био и
медиа — поток владельца компонента.

## Для чего этот экран

Карточка нужна, чтобы осмотреть состав, который вы позже можете
выбрать:

- целевой харнесс;
- назначение, поза, целевая роль (роли может не быть);
- каждый запиненный компонент с точным `X.Y`;
- агрегированные требования сетапа плюс его пинов;
- потенциальный бюджет контекста всего графа;
- `author_verified` и `component_verified` на **версии сетапа**.

Карточка **не**:

- запускает `setup compose`, `select propose` или `install apply`;
- подменяет вам более новый компонент;
- пишет нативные файлы в харнесс;
- считает перечисленные региональные сервисы исключительными рынками.

Сторонний компонент внутри графа сохраняет своего издателя. Автор
сетапа автоматически не становится автором каждого пина.

## Что на экране

**Назад в каталог** возвращает на
`/{locale}/catalog?include_experimental=1&resource=setups`.

### Шапка

| Элемент | Что показывает |
| --- | --- |
| Иконка | оформление сетапа, не глиф типа компонента |
| Заголовок | `latest_name` |
| Бейджи | Сетап, названные харнессы |
| Версия | `v{latest_version}` |
| Звёзды GitHub / В архиве | когда метаданные есть |
| Исходный код | источник паспорта, когда заявлен |

Действия совпадают с карточкой компонента: Нравится, Скопировать URL,
Скопировать ID, Скопировать CLI-команду, Пожаловаться на сетап.
Строка CLI использует `--kind setup`. Жалоба открывает
`/{locale}/reports?object_kind=setup&stable_id=…&version=…&digest=…`.

### Связи и тело

Страны и связанные сервисы — связанные, не исключительные.

Основная колонка:

| Блок | Содержимое |
| --- | --- |
| Описание | текст паспорта или каталога |
| Технические детали | lifecycle, дата публикации, основной харнесс, SPDX-лицензия |
| Компоненты | точные компоненты, которые этот сетап включает |
| Агрегированные требования | объединение требований сетапа и пинов |

Каждая строка состава называет:

- `stable_id` и запиненный `version`;
- тип компонента;
- владельца / автора (может отличаться от издателя сетапа);
- метку стороннего источника, когда пин не first-party;
- ссылку на публичную карточку компонента, когда пин есть в каталоге.

Пин, который не удалось загрузить, опускается из живой таблицы, а не
показывается как угаданный тип. Это тупик для этого участника, не
разрешение его выдумать.

Рельс:

| Блок | Содержимое |
| --- | --- |
| Автор | издатель сетапа, `author_verified` |
| Использование | просмотры страницы, скачивания артефакта |
| Бюджет контекста | потенциальные токены always-loaded vs on-use участников |
| Полный локальный отчёт | копия `ai-stp select impact --setup-id … --setup-version …` |
| Копия CLI | `ai-stp registry version --kind setup --id … --version …` |
| История версий | предложенные `X.Y`; пропуски намеренны |

**Публичный JSON паспорта** — паспорт сетапа, включая список пинов.
Копируйте его; не вставляйте туда секреты.

### Бюджет контекста

Панель оценивает **потенциальный** контекст, не фактический расход
модели. Ставка, которую вы вводите для оценки стоимости, остаётся в
браузере. Pricing API не вызывается. Runtime-integrated участники
говорят, что байты пакета были бы обманчивы.

Always-loaded участники входят каждый раз, когда сетап загружается.
Условные добавляются, только когда агент их использует.

### Доверие на сетапе

`author_verified` сетапа — издатель сетапа. У каждого пина своя пара
осей на карточке компонента. Подтверждённый автор сетапа не
подтверждает сторонний MCP внутри графа. Проверка
`setup_pin_aggregate` соединяет точные пины и их опубликованные
сводки проверок; она не заменяет чтение проваленного пина.

## Соответствующие команды CLI

```bash
ai-stp registry show --kind setup --id <stable_id> --json
ai-stp registry version --kind setup --id <stable_id> --version <x.y> --json
ai-stp registry acquire --json
ai-stp select impact --setup-id <stable_id> --setup-version <x.y> --json
ai-stp link web --json
```

`registry acquire` забирает один точный опубликованный граф сетапа
для локальной офлайн-компиляции. `select impact` сравнивает контекст,
стоимость токенов и возможности точных **локальных** версий сетапа —
сайт только копирует команду.

Состав и apply остаются в CLI:

```bash
ai-stp setup compose plan --json
ai-stp select propose --json
ai-stp install plan --json
```

Страницы: [Команды сетапа](../cli/setup.md),
[Выбор](../cli/select.md), [Установка](../cli/install.md).

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| `Страница не найдена` | плохой id сетапа или не публичный | [Каталог](catalog.md) с resource=setups |
| Строка состава отсутствует | этот пин не удалось прочитать | откройте страницу версии; не заполняйте дыру по памяти |
| Нет токенизируемых компонентов | бюджет пуст | запустите `select impact` локально |
| Ошибка бюджета контекста | точный артефакт недоступен | сначала fetch (`registry acquire` / `registry fetch`) |
| В жалобе нет digest | у latest нет digest паспорта | откройте `/versions/{version}` |
| Лайк требует входа | нет сессии | [Войти](login.md) |
| Установка из браузера | не предлагается | скопируйте CLI, затем provider apply |

Machine-проекция перечисляет назначение, целевую роль (или её
отсутствие), позу, пины, линию доверия и два бита verified. Галерею
состава она не рендерит.
