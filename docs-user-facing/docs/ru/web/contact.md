# Контакт

Контакт сохраняет сообщение, чтобы операторы могли ответить. Это
публичная форма на SaaS-профиле (`saas_public_pages`). Это не живой
чат, не консоль тикетов и не форма жалобы на версию каталога.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human | `/{locale}/contact` | всем, если флаг |
| Machine | `/{locale}/ai/contact` | всем, если флаг |

Иконка в шапке (клавиша `C`) и ссылка **Контакт** в подвале ведут
сюда. Self-hosted сборки компилируют `saas_public_pages` выключенным:
элемент исчезает, и маршрут не входит в публичную навигацию.

Отправить может кто угодно, вошедший или нет. Сессия не прикрепляется
как идентичность на этой форме. Жалобы на точную версию каталога
по-прежнему живут на [Жалобах](reports.md) после входа или в действии
Пожаловаться на карточке, которое заранее заполняет kind, id, version
и digest.

## Для чего этот экран

Контакт нужен, чтобы спросить про каталог, публикацию, provider или
безопасную установку, когда у вас нет точного digest объекта.

Используйте **Жалобу** каталога, когда указываете на одну неизменяемую
версию. GitHub issues — только если вы вносите вклад в репозиторий, не
для секретов аккаунта.

Контакт **не**:

- сбрасывает пароль (его нет; вход — OAuth);
- сливает аккаунты;
- принимает вложения;
- заводит staff-модерационный case, за которым можно следить;
- обходит гейты публикации.

## Что на экране

Две колонки на широких viewport: липкое вступление, затем карточка
формы.

| Поле | Подпись | Правила |
| --- | --- | --- |
| Имя | Имя | обязательно, max 120 |
| Email для ответа | Email для ответа | обязательно, email, max 254 |
| Тема | Тема | обязательно, max 160 |
| Сообщение | Сообщение | обязательно, min 10, max 4000 |
| Отправка | Отправить сообщение | отключена, пока pending или после успеха |

Подсказки на странице:

- Сообщение сохраняется вместе с email для ответа, который вы
  указываете. Не добавляйте секреты.
- Укажите публичный URL, `stable_id` или точную версию, если вопрос
  касается объекта каталога.
- Не добавляйте секреты, токены, приватные ключи и содержимое
  приватных репозиториев.

Тот же компонент формы можно открыть как диалог жалобы с карточки
каталога с `targetKind` `component`, `setup` или author. На самом
`/contact` цель — `other` / `contact`.

После успешного POST кнопка остаётся отключённой, и страница
показывает, что обращение принято. Лимиты частоты возвращают
`Слишком много обращений. Попробуйте позже.` Другие сбои:
`Не удалось отправить обращение.`

Переключатель Human / Machine: machine-Контакт — короткий документ с
заголовком, подзаголовком и ссылкой назад. Заполняемой формы в нём
нет.

## Соответствующие команды CLI

У жалоб каталога есть путь CLI. У публичной формы контакта — нет.

```bash
ai-stp report preview --json
ai-stp report confirm --json
ai-stp report list --json
```

`report preview` готовит ограниченный payload, не отправляя его.
`report confirm` отправляет один точный preview после явного флага.
`report list` перечисляет **ваши** закрытые case (CLI после входа).
Это близнец [Жалоб](reports.md), не этой страницы.

Команды `ai-stp contact` нет. Не направляйте сообщение в
`report confirm`, чтобы «написать в поддержку».

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| Контакта нет в шапке | `saas_public_pages` выключен | GitHub для репозитория, CLI для жалоб на объект |
| Отправить остаётся отключённым | уже отправлено в этом виде | перезагрузите, чтобы отправить ещё одно |
| Слишком много обращений | лимит частоты | подождите; не повторяйте в цикле |
| Не удалось отправить обращение | API или валидация | проверьте формат email; уберите секреты; повторите позже |
| На этой странице нет case id | контакт — не журнал жалоб | смотрите Жалобы после входа, если подавали с карточки |
| Оператор не отвечает на секрет | вы отправили токен | ротируйте токен; не пересылайте его сюда |
| Клавиша `C` ничего не делает | флаг выключен или фокус в поле ввода | ожидаемо на self-hosted |

Не вставляйте файлы `.env`, session cookies, токены provider или
приватные ключи. Подсказка про приватность — правило, не украшение.

## Контакт vs Жалоба vs GitHub

| Нужно | Страница | Нужен digest? | Нужна сессия? |
| --- | --- | --- | --- |
| Вопрос о продукте | эта страница | нет | нет |
| Эта точная версия вредна | [Жалобы](reports.md) | да | да |
| Пожаловаться с карточки каталога | заранее заполненные Жалобы | да | да |
| Патч в репозиторий | GitHub | n/a | аккаунт GitHub |
| Вопрос об обработке данных | эта страница или [Правовые документы](legal.md) | нет | нет |

Сохраняемые поля — имя, email для ответа, тема, сообщение и внутренняя
цель (`other` / `contact` на этом URL). Слота вложений нет, поэтому
логи и скриншоты нужно описывать, не загружать. Предпочитайте
публичный URL каталога вставке.

Лимит частоты — на клиента, не дневная квота в UI. Когда срабатывает,
подождите. Цикл Отправить продлит блокировку.

У machine-Контакта нет формы. Агент не должен выдумывать POST;
направьте человека на этот URL или используйте `report preview`, когда
объект известен.

Клавиша `C` — тот же URL, что иконка в шапке. Она ничего не делает,
когда `saas_public_pages` выключен. После успешной отправки
перезагрузите страницу, если нужно второе сообщение; отключённая
кнопка — на этот вид, не пожизненная блокировка.
