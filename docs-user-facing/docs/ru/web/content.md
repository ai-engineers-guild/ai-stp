# Материалы

Материалы — поток публикаций сайта: практические заметки о более
безопасных сетапах плюс точная запись того, что изменилось. Это не
справочник, не каталог и не OpenAPI.

Feature flag — `content_hub`. Публичный SaaS-профиль его включает.
Self-hosted выключает: шапка и подвал опускают Материалы, маршруты
дают 404.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human-индекс | `/{locale}/content` | всем, если флаг |
| Machine-индекс | `/{locale}/ai/content` | всем, если флаг |
| Human-запись | `/{locale}/content/{type}/{slug}` | всем, если опубликовано |
| Machine-запись | `/{locale}/ai/content/{type}/{slug}` | всем, если опубликовано |

`{type}` — одно из:

| Ключ типа | Подпись в индексе |
| --- | --- |
| `article` | Статья |
| `blog_post` | Практика |
| `changelog` | История изменений |
| `release_notes` | Заметки к релизу |

Эти четыре ключа — закрытое множество. Пятый тип даёт 404.

Записи локализованы: английские и русские файлы делят `type` и
`slug`. **Опубликованную** запись может читать кто угодно. Гейта
сессии, лайка и ветки комментариев нет.

**Черновики дают 404.** Файл с `draft: true` разбирается в репозитории
и никогда не попадает в список, не маршрутизируется, не получает
machine-проекцию. Внутренние черновики — не preview URL.

## Для чего этот экран

Материалы нужны, чтобы читать продуктовые тексты, которые не являются
справочником команд:

- как держать границу доверия видимой;
- что изменилось в реестре;
- заметки к релизу нумерованной линии.

[Справочник](docs.md) — для how-to, которые следят за CLI и сайтом.
[Каталог](catalog.md) — для объектов, которые можно установить.

Материалы **не**:

- публикуют компонент;
- меняют правовую политику (это [Правовые документы](legal.md));
- принимают пользовательские материалы в браузере;
- показывают будущие даты `published_at` (они проваливают снимок).

## Что на экране

### Индекс

| Элемент | Содержимое |
| --- | --- |
| Заголовок | Материалы |
| Описание | Практические заметки о безопасных сетапах coding agents и точная история изменений продукта. |
| Типы публикаций | четыре подписи типов |
| Главный материал | новейшая опубликованная запись, крупно |
| Последние публикации | остальные, сначала новые |

Каждая строка показывает тип, `published_at` (ISO-дата), заголовок,
описание. **Читать материал** открывает
`/{locale}/content/{type}/{slug}`.

Пустой индекс (нет опубликованных записей в этой locale) всё равно
рендерит шапку и пустой список последних. Это типизированная пустота,
не 404.

### Запись

| Элемент | Содержимое |
| --- | --- |
| Назад | ← Материалы |
| Тип | Статья / Практика / История изменений / Заметки к релизу |
| Дата | `published_at` |
| Заголовок | title из frontmatter |
| Описание | description из frontmatter |
| Теги | до двенадцати строк |
| Тело | Markdown; изображения из `/content/illustrations/…` |

Переключатель Human / Machine сохраняет type и slug. Machine-индекс
перечисляет заголовки и URL. Machine-запись — статья как Markdown.

JSON-LD отдаётся для краулеров. Это не паспорт.

## Соответствующие команды CLI

CLI хаба материалов нет. Каталог и справка остаются:

```bash
ai-stp registry search --json
ai-stp help --agent --json
ai-stp link web --json
```

`link web` может напечатать канонический URL сайта, когда цель —
поддерживаемый вид. Slug материалов — не `stable_id` каталога. Не
передавайте slug статьи в `registry show`.

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| В шапке нет Материалов | `content_hub` выключен | пользуйтесь MkDocs и Каталогом |
| `/{locale}/content` 404 | флаг выключен или опечатка в пути | [Карта веба](index.md) |
| Запись 404 | неизвестный type/slug, другая locale или **черновик** | откройте индекс; не угадывайте черновики |
| Пустой список последних | в этой locale ничего не опубликовано | смените locale или подождите |
| Нет изображения | иллюстрации нет в снимке | статья всё равно читается |
| Поиск MkDocs находит тему | справочник — другое дерево | это ожидаемо |
| Нельзя комментировать | комментариев нет | [Жалоба](reports.md) на объект или [Контакт](contact.md) |

Черновики лежат в `docs-user-facing/content/` для авторов. Это не
публичный preview. Запрос `?draft=1` их не открывает.

## Материалы vs документация vs правовое vs каталог

| Дерево | URL | Изменяемость | Черновики |
| --- | --- | --- | --- |
| Хаб материалов | `/{locale}/content/{type}/{slug}` | опубликованный снимок | 404 |
| Справочник | MkDocs и `/{locale}/docs` | Markdown, опубликованный git | флага draft нет |
| Правовые документы | `/{locale}/legal/{slug}` | неизменяемая редакция политики | n/a |
| Каталог | `/{locale}/catalog/…` | неизменяемый объект `X.Y` | неопубликованное 404 |

Типы закрыты. `blog_post` в UI подписан как Практика; путь всё равно
говорит `blog_post`. Не выдумывайте `tutorial` или `rfc`.

Паритет locale: у опубликованной английской записи есть русская пара
с тем же type и slug, и наоборот. Переключение `en` ↔ `ru` в шапке
сохраняет type и slug.

Machine-материалы — тело статьи. Это не паспорт и не OpenAPI.
