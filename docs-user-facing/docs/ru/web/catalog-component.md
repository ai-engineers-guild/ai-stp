# Карточка компонента

Карточка компонента — публичная страница одного компонента каталога.
Она показывает последнюю предложенную версию, факты паспорта,
проверки и медиа. Она не делает adopt компонента, не пишет паспорт и
не устанавливает его.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human | `/{locale}/catalog/components/{stable_id}` | всем |
| Machine | `/{locale}/ai/catalog/components/{stable_id}` | всем |
| Human-версия | `/{locale}/catalog/components/{stable_id}/versions/{version}` | всем |
| Machine-версия | `/{locale}/ai/catalog/components/{stable_id}/versions/{version}` | всем |

`{stable_id}` должен быть id компонента. Id сетапа, усечённый ULID или
имя дают 404. Неопубликованные, заблокированные или неизвестные id
тоже 404. Страница не говорит, какой из этих случаев случился.

Публичную карточку может читать кто угодно. Лайк, unlike и жалоба
требуют сессии. **Изменить био и медиа** появляется только когда
сессия владеет объектом; ведёт на
`/{locale}/objects/component/{stable_id}/edit`.

## Для чего этот экран

Карточка нужна, чтобы решить, годится ли эта точная версия в
кандидаты:

- вид (`instruction`, `skill`, `mcp`, `hook`, `command`, `agent`,
  `plugin`, `setting`);
- имена харнессов;
- `author_verified` и `component_verified` как отдельные биты;
- исходный репозиторий, коммит и путь;
- проверки безопасности и требования;
- бюджет контекста (потенциальные токены, не измеренное
  использование).

Карточка **не**:

- запускает `component adopt` или `component passport update`;
- применяет хук, стартует MCP-сервер или включает плагин;
- сохраняет значения окружения, которые вы вводите в оценку
  стоимости;
- считает звёзды GitHub сигналом безопасности.

Память, правила и вспомогательные инструменты — содержимое
`instruction`, `skill` или `setting`. На этой странице это не
отдельные виды.

## Что на экране

**Назад в каталог** возвращает на
`/{locale}/catalog?include_experimental=1&resource=components`.

### Шапка

| Элемент | Что показывает |
| --- | --- |
| Иконка типа | глиф одного из восьми видов |
| Заголовок | `latest_name` |
| Бейджи | тип компонента, названные харнессы |
| Версия | `v{latest_version}` |
| Звёзды GitHub / В архиве | когда метаданные есть |
| Исходный код | закреплённые ссылки на репозиторий из паспорта |

Действия:

| Действие | Нужна сессия | Эффект |
| --- | --- | --- |
| Нравится / Вам нравится | да | переключает реакцию |
| Скопировать URL / Поделиться | нет | канонический URL версии |
| Скопировать ID | нет | `stable_id` |
| Скопировать CLI-команду | нет | `ai-stp registry version --kind component --id {stable_id} --version {version}` |
| Пожаловаться на компонент | да | `/{locale}/reports?object_kind=component&stable_id=…&version=…&digest=…` |
| Изменить био и медиа | владелец | редактор презентации |

### Связи и тело

Связанные страны и региональные сервисы — связанные, не
исключительные. Компонент может назвать несколько рынков. Открытие
сервиса не прячет остальные.

Основная колонка:

| Блок | Содержимое |
| --- | --- |
| Описание | Markdown из SEO-сводки, иначе паспорт, иначе blurb каталога |
| Медиа | до пяти изображений, видео или YouTube id |
| Секции модели | дополнительные SEO-секции, когда есть |
| Технические детали | lifecycle, вид проекции, дата публикации, харнесс, SPDX-лицензия |
| Требования | имена переменных окружения, разрешения, endpoints, требуемые компоненты — **только имена**, никогда значения |
| Проверки безопасности | статус скана, процент, обязательные vs дополнительные движки |

Рельс:

| Блок | Содержимое |
| --- | --- |
| Автор | аватар издателя, отображаемое имя, `author_verified` |
| Использование | просмотры страницы, скачивания артефакта |
| Бюджет контекста | потенциальные токены; runtime-derived виды так и говорят |
| Копия CLI | точная строка `registry version` |
| История версий | предложенные номера `X.Y`; пропуски намеренны |

**Публичный JSON паспорта** спрятан за аккордеоном. Копируйте его как
JSON. Это машинная запись, свёрнутая выше, не хранилище секретов.
Секретов там быть не должно; если видите что-то похожее на токен,
пожалуйтесь на версию.

### Процент безопасности

Процент каталога — `passed / (passed + failed + warning)`.
Обязательные проверки закрывают публикацию. Дополнительные сканеры
могут быть неполными, не проваливая процент. Payload находок, которые
могут содержать секреты, скрыты. Как работает каждый движок:
[Проверки безопасности](../security-checks.md).

`author_verified` отвечает на «платформа подтвердила этого
издателя?». `component_verified` отвечает на «эта точная версия прошла
гейт?». Одно из другого не следует.

### Страница точной версии

`/versions/{version}` — один неизменяемый паспорт. Он добавляет
OS/arch, доказательства поддержки и digest этой версии. Предложенные
номера могут пропускаться; отсутствующие миноры — не баг каталога.

## Соответствующие команды CLI

```bash
ai-stp registry show --kind component --id <stable_id> --json
ai-stp registry version --kind component --id <stable_id> --version <x.y> --json
ai-stp registry fetch --json
ai-stp link web --json
ai-stp select blast-radius --json
```

`registry show` перечисляет опубликованные версии. `registry version`
— один `X.Y`. `registry fetch` копирует байты в локальный кэш.
`link web` печатает канонический URL сайта. `select blast-radius`
локальный: показывает, какие сетапы и target уже ссылаются на
компонент.

Adopt и публикация — не эта страница:

```bash
ai-stp component discover --json
ai-stp owner object show --json
```

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| `Страница не найдена` | плохой id, частный, заблокированный или никогда не публиковался | вернуться в [Каталог](catalog.md) |
| `Сервис временно недоступен` | API лежит | повторить; использовать кэш CLI, если уже fetch |
| Нет медиа | владелец ничего не опубликовал | не ошибка |
| Нет версий | ничего не предложено | не выдумывайте `X.Y` |
| Бюджет контекста недоступен | артефакт не токенизирован | запустите локальную команду impact из CLI |
| Оценка стоимости пуста | вы не ввели ставку | необязательно; ставка не сохраняется |
| Лайк отклонён | нет сессии | [Войти](login.md) |
| В жалобе нет digest | у latest ещё не было digest | откройте конкретный `/versions/{version}` |
| Изменить био нет | вы не владелец | ожидаемо |

Machine-проекция печатает `stable_id`, digest, `trust_lane`,
`author_verified`, `component_verified`, харнесс и шаблон команды
установки. Галерею она не рендерит.
