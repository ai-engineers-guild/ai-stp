# Профиль

Профиль — редактор публичной страницы издателя: display name, короткое
bio, HTTPS-ссылки и аватар. Save держит частный черновик. Publish
обновляет `/{locale}/publishers/{account_id}`.

Это оформление. Это не паспорт компонента, не `author_verified` и не
теги каталога.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human editor | `/{locale}/account/profile` | вошедшему владельцу |
| Machine editor | `/{locale}/ai/account/profile` | та же сессия |
| Human preview | `/{locale}/account/profile/preview` | вошедшему владельцу |
| Machine preview | `/{locale}/ai/account/profile/preview` | та же сессия |

Нет сессии → login. Онбординг pending → онбординг. Посетители этот
редактор не видят; они видят [Издателей](publishers.md) после
публикации.

Превью **временное и не сохраняется**. Рендерит текущий черновик
(или пустоту). Это не второй публичный URL.

## Зачем этот экран

Профиль задаёт, что посетитель читает на вашей странице издателя.

**Изменить био и медиа** компонента — оформление каталога одного объекта.
`component passport update` в CLI — заявленные факты. Эти три слоя
нельзя смешивать.

Профиль **не**:

- меняет `account_id`;
- ставит `author_verified` или `component_verified`;
- публикует версию компонента;
- допускает HTML или `javascript:` в bio;
- хранит больше восьми HTTPS-ссылок.

## Что на экране

Ссылка назад на [Аккаунт](account.md). Заголовок **Публичный профиль**.
Подзаголовок объясняет display name, короткое bio, ссылки и аватар.

| Элемент | Подпись | Правила |
| --- | --- | --- |
| Avatar | Загрузить фото | JPEG, PNG или WebP до 5 MB; квадрат ≥ 512×512 рекомендуется |
| | Взять из GitHub / Взять из Google | импорт из связанной идентичности |
| | Удалить | снять опубликованный аватар |
| Display name | Display name | публичная строка |
| Короткое bio | Короткое bio | ограниченный Markdown; слишком длинный или небезопасный URI отказ |
| Режим bio | Текст / Рендер | редактор vs превью bio |
| Ссылки | Метка + URL (HTTPS) | до восьми; Добавить / Удалить |
| Сохранить | Сохранить | частный черновик |
| Опубликовать | Опубликовать | обновляет публичную страницу |
| Вернуть опубликованные данные | — | подгружает последнюю опубликованную редакцию в редактор |
| Предпросмотр | Предпросмотр | `/{locale}/account/profile/preview` |

Чипы статуса: Опубликовано, Черновик, Не опубликовано. Подсказка:

> «Сохранить» оставляет приватный черновик. «Опубликовать» обновляет
> публичную страницу.

Markdown bio допускает списки, заголовки, emoji, таблицы, ссылки,
жирный и код. HTML и небезопасные URI падают с **Bio не должен содержать
HTML или небезопасные URI**.

Неудачный save или publish — toast. Отказ аватара отделён от сохранения
черновика: отклонённый файл не хранится.

### Страница превью

Баннер: **Предпросмотр — временно и без сохранения**. **Редактировать
публичный профиль** возвращает в редактор. Пустой черновик: **Пока
нечего показывать.**

Human / Machine: machine profile печатает `display_name` и `bio`.
Machine preview печатает баннер и поля проекции.

## Совпадающие команды CLI

Редактора профиля в CLI нет. Связанные чтения:

```bash
ai-stp auth status --json
ai-stp link web --json
ai-stp owner objects --json
```

`link web` может напечатать публичный URL издателя, когда известен
account id (скопируйте его с Account). `owner objects` перечисляет
объекты каталога; bio он не патчит.

Работа с паспортом остаётся в CLI и это другой документ:

```bash
ai-stp passport developer show --json
ai-stp component passport show --json
```

Не вставляйте bio профиля в паспорт, чтобы «опубликовать крепче».

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| Редирект на login | нет сессии | войти |
| Avatar rejected | тип, размер или скан | JPEG/PNG/WebP ≤ 5 MB |
| Bio is too long | сверх лимита | сократите |
| Bio unsafe URI | HTML или `javascript:` | HTTPS-ссылки текстом |
| Could not publish | нет редакции черновика | сначала Save, потом Publish |
| Preview empty | в черновике ничего | введите имя или bio |
| Публичная страница старая | Save без Publish | нажмите Publish |
| Публичная страница 404 | флаги приватности скрывают | приватность на [Аккаунте](account.md) |
| Import from GitHub нет | эта идентичность не связана | сначала свяжите на Account |

Секретам в bio не место. Токены в Markdown — всё ещё токены.

## Черновик против публикации

```text
empty → Save → Draft (private)
Draft → Publish → Published (public publisher page)
Published → edit → Save → Draft ahead of the live page
Published → Restore currently published data → editor matches live
```

Посетители Draft не видят. Превью — только ваши глаза. Флаги
приватности всё ещё могут скрыть Published: тогда URL издателя даёт
404, хотя редактор говорит Published. Это чинится на Account, не здесь.

Ссылки: label — человеческий текст; URL должен быть HTTPS. `http://` и
не-URL на save отказывают. Восемь — жёсткий потолок.

Machine profile — `display_name` и `bio` **редактируемой** записи,
это может быть черновик. Machine preview — проекция с баннером
«не сохранено». Ни то ни другое не дайджест паспорта.
