# Лайки

Лайки — полка после входа с объектами каталога, которые вы отметили
Нравится. Это личный список на потом. Это не движок рекомендаций, не
линия доверия и не очередь установки.

## URL и кто их видит

| Проекция | URL | Кому видно |
| --- | --- | --- |
| Human | `/{locale}/likes` | после входа |
| Machine | `/{locale}/ai/likes` | та же сессия |

Подпись меню аккаунта — **Мои лайки**. Лайков нет в основной шапке.
Нет сессии → вход с `returnTo=/{locale}/likes`.

Другие люди ваш список не видят. Страницы издателей не показывают,
кто лайкнул объект. Публичная карточка показывает только счётчик.

## Для чего этот экран

Лайки нужны, чтобы снова открыть компонент или сетап, который вы
сохранили при просмотре.

Лайки **не**:

- закрепляют версию (карточка всё равно движется с `latest_version`);
- выдают доступ к частному объекту;
- заменяют `select` или `install`;
- включают экспериментальные объекты, которые вы никогда не лайкали
  (список — не поиск каталога);
- живут как публичный знак качества.

Unlike с карточки или из этого списка убирает объект отсюда.

## Что на экране

Шапка: иконка сердца, **Сохранённые объекты**, заголовок **Мои
лайки**, подзаголовок **Компоненты и сетапы, которые вы отметили,
чтобы вернуться к ним позже.**, и счётчик.

Пусто:

- **Вы пока ничего не лайкнули**
- **Откройте каталог и нажмите «Лайк» у подходящего компонента или
  сетапа.**
- Кнопка **Перейти в каталог** →
  `/{locale}/catalog?include_experimental=1`

Непусто: тот же смешанный layout `CatalogResults`, что и каталог
(сетапы и компоненты как карточки/список), без разделения
экспериментальной полосы (только лайкнутые id). Действия на карточке
по-прежнему включают Не нравится, Скопировать CLI-команду, Скопировать
ID, Пожаловаться.

Human / Machine: machine-Лайки перечисляют `object_kind` и
`stable_id` плюс ссылки на публичные карточки.

Лайк на карточке каталога требует сессии. Анонимные клики ведут на
Вход; после возврата лайкните снова.

## Соответствующие команды CLI

CLI лайков нет. Связанные чтения каталога:

```bash
ai-stp registry show --kind component --id <stable_id> --json
ai-stp registry show --kind setup --id <stable_id> --json
ai-stp registry version --kind component --id <stable_id> --version <x.y> --json
ai-stp link web --json
```

Лайк — не пин. Если позже нужны байты, `registry fetch` или
`registry acquire` в CLI. Если нужна установка,
[Установка](../cli/install.md).

## Тупики

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| Пустая полка | нет реакций | смотрите каталог |
| Редирект на вход | нет сессии | войти |
| Карточка 404 из этого списка | объект ушёл из публичного каталога | Unlike; открыть нельзя |
| Счётчик на карточке ≠ ваш список | счётчик глобальный | ожидаемо |
| Лайкнули, но всё ещё experimental | лайк — не согласие | `select` всё равно спросит экспериментальное согласие |
| Смешанный список выглядит неупорядоченным | тот же смешанный рендерер, что каталог | откройте карточку; не выводите ранг |
| Нет Лайка без входа | нужна сессия | [Войти](login.md) |

Не считайте высокий счётчик лайков за `component_verified`. Оси
остаются независимыми.

## Типичный путь

1. Войдите (лайки привязаны к аккаунту).
2. Откройте [Каталог](catalog.md), Both-режим, экспериментальные
   включены или выключены как хотите.
3. На карточке выберите Нравится. Сердце заполняется; глобальный
   счётчик растёт.
4. Откройте Мои лайки из меню аккаунта. Объект там с теми же
   действиями карточки.
5. Unlike убирает его с этой полки и уменьшает счётчик. Объект
   каталога он не удаляет.

Если сессия истечёт между 3 и 4, полка пуста, пока вы снова не
войдёте — реакция на сервере, не в localStorage.

## Чем лайк не является

| Действие | Лайк? | Настоящая команда или страница |
| --- | --- | --- |
| Закрепить `X.Y` | нет | `registry version --version` |
| Согласие на experimental | нет | CLI `consent allow` |
| Грант major-линии | нет | [Доступ](access.md) |
| Установка | нет | `install plan` / provider |
| Подтвердить содержимое | нет | `component_verified` на версии |

Machine-проекция `/likes` — список ссылок kind + `stable_id`. Агент
не должен считать этот список матрицей eligibility.

Смешанный рендерер на этой странице не пагинирует как каталог:
сервер возвращает список реакций целиком. Отсутствующая карточка —
404 по клику, не тихая дыра в JSON. Unlike — единственная запись.

Если вы лайкнули объект, чтобы «запомнить digest», скопируйте URL
версии или команду `registry version` в момент лайка. Полка хранит
`stable_id`, не замороженный `X.Y`.
