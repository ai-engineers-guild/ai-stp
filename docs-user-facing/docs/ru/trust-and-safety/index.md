# Доверие и безопасность

Опубликованные версии сетапов и компонентов точны и неизменяемы. Механические
проверки совместимости, доступа и доверия определяют допустимость кандидата.
Разрешение пользователя не превращает непроверенные байты в проверенные
и не отменяет механический отказ.

Только аутентифицированный публичный установочный компонент записывает итоговую
конфигурацию харнесса. Изменение активного агента требует подготовки и перезапуска.
CLI не устанавливает, не фиксирует и не обновляет исполняемый файл харнесса.
Телеметрия установки не отправляется.

Читайте [результаты проверок](../security-checks.md); для
[восстановления](../troubleshooting/index.md) используйте сохранённую операцию.
Учётные данные не должны попадать в промпты и логи.
