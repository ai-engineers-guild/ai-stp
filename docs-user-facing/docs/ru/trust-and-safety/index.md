# Доверие и безопасность

Перед применением проверьте версию сетапа, дайджест артефакта, цель и
обязательные результаты проверок. Верификация автора относится к личности.
Проверка артефакта относится к конкретным байтам и выполненным процедурам.

Нативный CLI записывает проверенную по плану конфигурацию. При перезапуске
квитанция передачи фиксирует новый процесс харнесса. Читайте
[результаты проверок](../security-checks.md) и используйте исходную операцию
для [восстановления](../troubleshooting/index.md). Учётные данные храните
в выбранном хранилище.
