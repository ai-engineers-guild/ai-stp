# Диагностика

Начинайте с команды:

```bash
ai-stp doctor --json
```

Она показывает состояние CLI, окружения, локального реестра, устройства и
доступных возможностей.

## Команда не найдена

Проверьте установку:

```bash
uv tool list
```

Если `ai-stp-cli` установлен, но команда недоступна, проверьте, что каталог
`uv` tools находится в `PATH`.

## Нет аккаунта

Аккаунт не нужен для локального режима и анонимного чтения публичного
каталога. Авторизация нужна для приватных объектов, синхронизации, публикации,
устройств и grants.

## Нет сети

Локальный режим должен продолжать работать после первичной настройки.
Публичный каталог может быть доступен из кэша, если объект уже был подтверждён
платформой.

## Ошибка установки

Не удаляйте target и резервные копии вручную. Проверьте plan, журнал операции
и состояние provider, затем используйте штатное восстановление.
