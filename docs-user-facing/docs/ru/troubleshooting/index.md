# Диагностика

Сначала проверьте версию, окружение и текущие задачи:

```bash
ai-stp version --json
ai-stp doctor --json
ai-stp task list --json
```

Если CLI отсутствует, используйте [инструкцию нативной установки](../quickstart/human.md).
Python-реестр требует явного переноса, а не повторной инициализации.
Продолжайте задачу по сохранённому id и текущей revision. Для принятого плана
используйте исходные план и digest; не создавайте поверх него другую операцию.
Истёкший непринятый план создаётся заново. Принятые операции восстанавливаются вперёд.

При ошибках аккаунта проверьте account status и при необходимости создайте
новый план. Старый код браузера нельзя продлить повторным подтверждением.
Не помещайте секреты в логи. Отказ платформы — реальное ограничение:
выполнение провайдеров сейчас требует Linux. Backup/restore не обходят проверки.
