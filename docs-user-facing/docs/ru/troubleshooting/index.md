# Устранение неполадок

```sh
ai-stp version --json
ai-stp doctor --json
ai-stp configuration native pending --json
```

Используйте исходный каталог состояния. Для задачи прочитайте текущую ревизию
через `task status`. Для настройки сохраните ID операции и дайджест из `pending`,
затем прочитайте справку по восстановлению. Перед применением подготовленного
плана может потребоваться завершить исходный процесс харнесса.

Если CLI отсутствует или нужно перенести Python-состояние, откройте
[руководство установки](../quickstart/human.md). При ошибке входа проверьте
статус аккаунта и начните новую авторизацию, если код истёк.
