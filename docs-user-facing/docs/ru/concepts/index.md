# Понятия

## Харнесс

Харнесс — CLI-среда, в которой работает coding agent. В MVP основная поддержка
есть у Claude Code, Codex и Grok Build; Pi и OpenCode идут как beta.

Подробнее: [поддерживаемые харнессы](../harnesses.md).

## Сетап

Сетап — полная конфигурация одного харнесса. Он принадлежит конкретному
харнессу с момента создания и закрепляет точные версии компонентов.

Любое изменение состава создаёт новую версию сетапа.

## Компонент

Компонент — отдельная часть сетапа одного из видов:

- `instruction`;
- `skill`;
- `mcp`;
- `hook`;
- `command`;
- `agent`;
- `plugin`;
- `setting`.

Память, правила, параметры и вспомогательные инструменты являются содержимым
`instruction`, `skill` или `setting`, а не отдельными видами компонента.

Подробнее: [виды компонентов](../components/index.md).

## Паспорт

Паспорт — версионируемое машиночитаемое описание объекта. Через паспорта
`ai_stp` связывает происхождение, совместимость, ограничения и результаты
проверок.

## Линия доверия

Линия доверия определяет, как объект попадает в выдачу:

- `authoritative`;
- `experimental`;
- `local_owner_or_pinned`.

Непроверенный объект не участвует в автоматической установке без явного
согласия пользователя.
