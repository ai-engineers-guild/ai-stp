# Быстрый старт для ИИ-агента

Начинайте с реестра доступных задач. Выбирайте author или install только для
соответствующей цели; для аккаунта, синхронизации, публикации и других операций
используйте справку нужной группы. Не придумывайте intent по старому примеру.

```bash
ai-stp task intents --json
ai-stp task input-schema --intent install --json
```

Для авторинга нужны абсолютный каталог источника, harness, вид компонента, имя
и лицензия. Для установки соберите все поля схемы, точные setup/provider/source
и корни областей. Сохраните ограниченный JSON в локальный файл и начните задачу
с уникальным idempotency key. Выполняйте argv продолжения только при actor=cli.
Не путайте постоянный task id с идентификатором процесса инструмента выполнения.
Продолжайте задачу с её текущей revision.

Не устанавливайте и не обновляйте harness. Провайдеры setup-систем — компоненты
установки ai-stp; на Linux только они записывают конечное состояние. Изменение
активного окружения требует подготовки и перезапуска. На macOS и Windows
выполнение провайдеров в этом релизе недоступно. План ещё не означает установку.

Подробная процедура — в [каноническом skill](https://github.com/ai-engineers-guild/ai-stp/blob/main/skills/canonical/ai-stp/SKILL.md).
Поля и команды определяет реестр исполняемого CLI.
