# Быстрый старт для агента

Читайте реестр задач для авторинга и справку по нативной настройке:

```sh
ai-stp task intents --json
ai-stp task input-schema --intent author --json
ai-stp help --path "configuration native" --json
```

Для нового сетапа используйте `configuration native`. Укажите точную версию
сетапа, дайджест паспорта и корни установки. Проверьте план, затем подготовьте
и примените его с исходным дайджестом. Если план требует передачи сессии,
выполните перезапуск по [процедуре установки](https://github.com/ai-engineers-guild/ai-stp/blob/main/apps/cli/README.md#setup-configuration).

В продолжении задачи выполняйте готовый argv при `actor` равном `cli`.
После сбоя прочитайте исходную задачу или операцию перед повтором. Сохраните
каталог состояния, ревизию задачи или ID операции и дайджест плана.
