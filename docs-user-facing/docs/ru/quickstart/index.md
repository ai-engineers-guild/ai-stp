# Начало работы

[Для человека](human.md): установите проверенный нативный архив и создайте новое
состояние или явно перенесите существующее.

[Для агента](agent.md): получите актуальные намерения и схемы входных данных;
выполните разрешённую операцию с сохранённым планом и результатами.
