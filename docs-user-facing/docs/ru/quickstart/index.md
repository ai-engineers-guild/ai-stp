# Быстрый старт

Два читателя начинают с разных мест. Команды — один и тот же CLI; ритуал —
нет.

- **Человек** ставит бинарник, создаёт локальную идентичность и читает
  каталог. Дальше — [Быстрый старт для человека](human.md).
- **ИИ-агент** каждую сессию начинает с `doctor` и machine help и не должен
  собирать флаги из памяти. Дальше —
  [Быстрый старт для ИИ-агента](agent.md).

Исполняемый файл — `ai-stp`. Дистрибутив на PyPI — `ai-stp-cli`. Команда
`uv tool install ai-stp` ставит пакет, который этот проект не публикует.

Выбор и применение сетапа — не эта глава. После первого чтения каталога
смотрите [Выбор](../cli/select.md) и [Установку](../cli/install.md).
