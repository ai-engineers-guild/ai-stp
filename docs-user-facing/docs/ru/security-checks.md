# Проверки безопасности

Проверяйте доказательства для точного артефакта, целевого окружения и политики.
Идентичность автора и проверка компонента независимы. Успешный скан подтверждает
результат в пределах своей проверки, а не безопасность любого возможного поведения.

Недоступный сканер, тайм-аут или некорректный пакет означают неполную проверку,
а не успех и не обнаружение вредоносного содержимого. Неприменимые проверки
не запускаются. Политика и модели результатов worker определяют необходимые
проверки; интерфейс показывает полученные результаты.

Следуйте механическому решению CLI. Не обходите отказы совместимости, доступа,
целостности и обязательных проверок. См. [доверие](trust-and-safety/index.md).
