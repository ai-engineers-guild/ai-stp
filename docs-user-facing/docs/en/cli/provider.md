# Provider

Setup-system releases are ai-stp installation components. Exact release artifacts and provenance are verified before the provider writes final harness configuration.

```bash
ai-stp help --path provider --json
```

Inspect the returned parameters before a mutation. Plans bind exact inputs and digests; repeat an admitted operation with its original plan for recovery.
