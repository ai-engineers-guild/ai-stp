# Publication

Publish an exact immutable object graph with explicit visibility and provenance. A confirmed plan is not proof that the public catalog can read the result.

```bash
ai-stp help --path publication --json
```

Inspect the returned parameters before a mutation. Plans bind exact inputs and digests; repeat an admitted operation with its original plan for recovery.
