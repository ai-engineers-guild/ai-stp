Sync is explicit and account-bound. Review the plan and origin, then apply its exact digest. Login does not upload local objects.

```bash
ai-stp help --path sync --json
```

Inspect the returned parameters before a mutation. Plans bind exact inputs and digests; repeat an admitted operation with its original plan for recovery.
