# Catalog

Public objects are readable without an account. Sign in through the web when
private objects, publication, grants or sync require an account. The CLI owns
selection, assembly and installation; the web displays objects and evidence.

A setup configures one harness and references exact component versions. Inspect
provenance, license, compatibility and current verification evidence before applying
it. Author verification concerns identity; it is separate from byte verification.
A successful catalogue read is not an installation result.

Use the [CLI registry](../cli/index.md) to discover catalog and publication commands.
The agent gathers exact setup coordinates and target roots before starting install.
