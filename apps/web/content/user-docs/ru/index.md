ai_stp — каталог и детерминированный сборщик сетапов для AI coding harnesses. Он сохраняет происхождение, совместимость, точные версии и решения о доверии видимыми.

## С чего начать

1. Установите CLI и войдите.
2. Найдите компоненты или готовый сетап.
3. Проверьте паспорт и ограничения совместимости.
4. Примените конфигурацию через публичный провайдер харнесса.

## Основные объекты

- **Компонент** — instruction, skill, MCP, hook, command, agent, plugin или setting.
- **Сетап** — полная конфигурация одного харнесса с закреплёнными версиями.
- **Паспорт** — неизменяемая машиночитаемая идентичность опубликованной версии.
