title: Быстрый старт
description: Установка CLI, авторизация устройства и первый просмотр каталога.

## Проверка CLI

```shell
ai-stp version
ai-stp doctor
```

## Вход и авторизация установки

```shell
ai-stp auth device
```

Откройте показанный URL, введите одноразовый код и вернитесь в терминал.

## Каталог

```shell
ai-stp registry search
ai-stp setup show <setup_id>
```
