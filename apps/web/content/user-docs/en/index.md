ai_stp is a catalog and deterministic setup builder for AI coding harnesses. It keeps provenance, compatibility, exact versions, and trust decisions visible.

## Start here

1. Install the CLI and sign in.
2. Browse components or complete setups.
3. Inspect the passport and compatibility constraints.
4. Apply through the public provider for your harness.

## Core objects

- **Component** — one instruction, skill, MCP server, hook, command, agent, plugin, or setting.
- **Setup** — a complete, version-pinned configuration for one harness.
- **Passport** — the immutable machine-readable identity of a published version.
