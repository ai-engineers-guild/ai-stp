title: CLI commands
description: The main command groups used to inspect, select, sync, and recover.
---

## Discovery

Use `registry search`, `component inspect`, and `setup show` to read public facts without changing a target.

## Selection and installation

Selection creates a deterministic proposal. Review composition and conversion reports before confirming an apply operation.

## Recovery

Use `doctor`, `status`, and recovery reports before changing an unhealthy target. Never edit an active harness target in place outside its provider.
