---
title: Quickstart
description: Install the CLI, authorize a device, and inspect the catalog.
---

## Install and verify

```shell
ai-stp version
ai-stp doctor
```

## Sign in and authorize this installation

```shell
ai-stp auth device
```

Open the shown URL, enter the one-time code, then return to the terminal.

## Browse

```shell
ai-stp registry search
ai-stp setup show <setup_id>
```
