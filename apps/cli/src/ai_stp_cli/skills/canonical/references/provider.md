# Provider and toolchain

User intents: install the provider, pin the toolchain, install a harness
program.

Resolve from machine help: `ai-stp provider fetch`, `ai-stp provider trust`,
`ai-stp provider check`, `ai-stp provider conformance`,
`ai-stp provider update plan`, `ai-stp toolchain install`,
`ai-stp harness install`, `ai-stp harness status`.

Release trust and conformance are both required. A signature is not
compatibility. Verify with `ai-stp provider check` and `ai-stp harness status`.
