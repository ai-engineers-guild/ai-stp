# Envelope

Каждая команда с `--json` печатает ровно один объект.

При `ok: true` результат в `data`. `warnings` можно показать, не делая вызов
неуспешным. При `ok: false` `error.code` — стабильный код из закрытого реестра,
а `next_actions` называет разумный следующий шаг.

Найдите `error.code` в `error_codes` из machine help и следуйте `handling`,
вместе с `retryable` и `next_actions` ответа. Не выбирайте действие только по
классу кода выхода: один класс может быть конфликтом, устаревшим планом или
запросом решения пользователя.

Повторяйте только при `retryable: true`. После неподтверждённого timeout сначала
проверьте фактический эффект через предложенную status или recovery команду.

`next_actions` — упорядоченная подсказка, не разрешение. Перед следующим вызовом
снова прочитайте дескриптор.
