# Install a complete setup

Прочитайте актуальную install-схему: нужны точные координаты сетапа, харнесс и явные корни областей. Запуск задачи разрешает указанную операцию и может сразу её выполнить. Install поддерживает установку, замену и удаление, но не выбирает неуказанный сетап. Для активного агента используйте staged handoff и подтверждение из перезапущенного процесса. Не создавайте бэкапы и не редактируйте целевую конфигурацию вручную.
