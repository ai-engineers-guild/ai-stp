# Быстрый старт

## Установить CLI

CLI устанавливается как обычный `uv` tool:

```bash
uv tool install ai-stp-cli
```

После установки проверьте, что команда доступна:

```bash
ai-stp version
ai-stp doctor --json
```

`doctor` показывает состояние окружения, доступные возможности и проблемы,
которые нужно исправить до сборки сетапа.

## Подготовить устройство

Для локальной работы без аккаунта создайте паспорт разработчика и устройство:

```bash
ai-stp passport developer init --json
ai-stp device init --json
```

Устройство получает `device_id` и ключ. Приватный ключ хранится в системном
хранилище секретов, а если оно недоступно, CLI явно сообщает файловый ярус.

## Посмотреть каталог

Анонимное чтение публичного каталога доступно без входа:

```bash
ai-stp registry search --json
```

Для точного объекта используйте `show`. Если сеть недоступна, CLI может вернуть
последнюю подтверждённую копию из локального кэша и покажет момент проверки.

## Что дальше

После первого `doctor` агент читает машинную справку:

```bash
ai-stp help --agent --json
```

Эта справка является источником команд для Agent Skill. Агент не должен
придумывать команды из памяти, если CLI уже умеет отдать их машинно.

=== "Я выбираю готовый сетап"
    Откройте [каталог](catalog/index.md), проверьте линию доверия, совместимость
    с вашим [харнессом](harnesses.md) и состав компонентов.

=== "Я собираю свой сетап"
    Начните со страницы [компонентов](components/index.md): она помогает решить,
    что оформить как `skill`, что как `mcp`, а что оставить в `setting` или
    `instruction`.

=== "Я автор компонента"
    Посмотрите [публикацию](publishing/index.md) и правила доверия. Публикуемая
    версия неизменяема, поэтому лучше проверить паспорт до первого релиза.
