# CLI

CLI — главный пользовательский интерфейс `ai_stp` для сборки, проверки и
установки сетапов. Веб показывает каталог и аккаунт, но не применяет
конфигурацию к харнессу.

## Команды наблюдения

Команды наблюдения ничего не создают и не меняют:

```bash
ai-stp version
ai-stp doctor --json
ai-stp capabilities --json
ai-stp help --agent --json
ai-stp config show --json
ai-stp auth status --json
ai-stp device show --json
```

На пустой установке они возвращают типизированное состояние, а не молча
инициализируют устройство.

## Команды изменения

Команды изменения явно заявляют действие:

```bash
ai-stp device init --json
ai-stp passport developer init --json
ai-stp passport developer update --json
ai-stp passport device refresh --json
```

Опасные действия требуют подтверждения. Например, reset устройства не должен
происходить как побочный эффект диагностики.

## Телеметрия установки

По умолчанию выключена. После явного согласия CLI отправляет один анонимный
запрос на каждый фактически установленный компонент — что и зачем, описано в
[Телеметрии установки](telemetry.md).

```bash
ai-stp telemetry show --json
```

## Agent Skill

Agent Skill начинает с:

```bash
ai-stp doctor --json
ai-stp help --agent --json
```

После этого агент использует машинный список команд из CLI. Это защищает от
устаревших инструкций и галлюцинированных флагов.

| Стадия | Команда | Зачем |
| --- | --- | --- |
| Проверить окружение | `ai-stp doctor --json` | понять, что доступно и что сломано |
| Узнать возможности | `ai-stp capabilities --json` | не предполагать поддержку харнесса |
| Получить machine help | `ai-stp help --agent --json` | использовать актуальные команды |
| Найти объект | `ai-stp registry search --json` | выбрать сетап или компонент |
| Посмотреть объект | `ai-stp registry show <stable_id> --json` | проверить паспорт перед решением |

!!! note "Команды в документации — пользовательский ориентир"
    Если CLI отдаёт более свежую machine help, агент должен следовать ей.
    Документация объясняет модель, а не заменяет исполнимую справку CLI.
