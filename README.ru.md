# ai-stp

[English](README.md) · [Каталог](https://ai-stp.aiguild.space) ·
[Релизы CLI](https://github.com/ai-engineers-guild/ai-stp/releases?q=cli-v)

ai-stp — CLI на Rust для создания, проверки, выбора и установки конфигураций
ИИ-харнессов. Основной пользователь CLI — ваш агент. Для локальной работы не нужны
аккаунт, Python или ключ модели. Веб отвечает за аккаунт и публичный каталог;
движком системы остаётся CLI.

## Начало работы

Скачайте нативный архив, проверьте контрольную сумму и аттестацию GitHub.
[Руководство CLI](apps/cli/README.md) описывает установку и перенос существующего
состояния. Из исходников: `cargo install ai-stp-cli --locked`. Тот же бинарник
доступен через `uv tool install ai-stp` и `pip install ai-stp`. Старый PyPI-проект
`ai-stp-cli` — отдельный пакет: сначала удалите его команду через управляющий
ею пакетный менеджер.

```sh
ai-stp init --credential-store os_keyring --json
ai-stp task intents --json
ai-stp help --agent --json
```

CLI собирает и проверяет конфигурацию; установочный компонент харнесса записывает
её в целевое окружение. Системы сетапов встроены в этот процесс и сохраняют свои
репозитории. Сам харнесс устанавливает и обновляет пользователь или его поставщик.

CI проверяет Linux x86-64, macOS Apple Silicon и Windows x86-64. Изолированная
установка сетапов и передача активной сессии пока доступны на Linux; остальные
платформы возвращают явный отказ для этой операции.
