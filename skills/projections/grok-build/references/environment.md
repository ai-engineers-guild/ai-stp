# Environment

User intents: configure this project, prepare several harnesses, install the
programs and tools needed by selected setups.

Resolve from machine help: `ai-stp environment inspect`, `ai-stp environment plan`,
`ai-stp harness install`, `ai-stp harness status`, `ai-stp toolchain profile`,
`ai-stp toolchain install`, `ai-stp component program install`,
`ai-stp component program status`, `ai-stp install transaction approve`,
`ai-stp install transaction apply`, `ai-stp install transaction status`,
`ai-stp install transaction recover`.

Inspect the project and select exact setup versions. Keep each setup attached
to its own harness. Inspect their prerequisites and any explicitly selected
toolchain tools. Execute applicable preparation actions within task authority,
then inspect again. Installed program evidence, authorization and verified
native configuration are separate facts; an unobserved fact is not ready.

Plan each harness configuration and compose the exact child plans. Review
native path conflicts before any write. Apply the aggregate digest through its
coordinator and retain each preserved setup identity. On failure follow the
aggregate's recovery path; do not replay individual children independently.

Shared executable versions remain separate from a harness's native snapshot.
Use the exact required program version. Returning one setup never authorizes
deleting a shared tool or another project's runtime.
