# Local identity

Для первого запуска используйте `ai-stp init` с явно выбранным хранилищем из machine help. Повтор сохраняет ключ; `ai-stp device show` проверяет идентичность. Планы паспортов применяет общий local apply. Отсутствие ключа не разрешает сброс аккаунта; чтение не должно создавать состояние.
