# Установка и обновление control Skill

Берите из установленного machine help `ai-stp skill status`,
`ai-stp skill install` и `ai-stp skill remove`.

Выберите каталог, который реальный харнесс обнаруживает как Skill; конечный
каталог назовите `ai-stp`. Используйте поддерживаемые дескриптором harness и
locale. Ставьте полный пакет через CLI: копирование только SKILL.md теряет
playbook.

Прочитайте status и выполните install. Повторная установка обновляет неизменённый
owned-пакет до версии, входящей в CLI. Снова прочитайте status и проверьте
ownership, harness, locale и package digest. Если харнесс ещё читает старую
копию, освежите обнаружение или начните новую сессию.

`foreign` означает отсутствие ownership claim. `stale` означает правки
установленного пакета. Осмотрите и сохраните их до выбора отдельной установки
либо явно запрошенной замены. Не удаляйте каталог вслепую.

Сохраняйте этот control Skill при переключении и удалении пользовательских
сетапов: это процедура управления CLI, а не заменяемый сетап.
