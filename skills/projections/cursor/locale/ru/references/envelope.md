# Machine results

Дождитесь завершённого JSON-конверта stdout. ok не равен выполненной бизнес-цели: читайте state, goal_satisfied, outcome и pending_operation. error_codes/handling принадлежат machine help. retryable: true допускает ограниченный повтор того же намерения; неподтверждённый timeout требует status/readback. argv передаётся массивом аргументов, не shell-строкой.
