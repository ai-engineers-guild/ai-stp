# Install a complete setup

Для нового сетапа прочитайте `ai-stp help --path "configuration native" --json`.
Укажите точную локальную версию, дайджест паспорта, харнесс и корни. Проверьте
и подготовьте план, затем примените исходную операцию с её дайджестом.
Для активного харнесса выполните передачу сессии по плану. Сохраните каталог
состояния и восстановите прерванную операцию через `pending` и `status`.

Сохранённую операцию внешнего провайдера восстанавливайте по её исходной
схеме задачи и ревизии.
