# First run

Начните с `ai-stp task intents --json`. Если CLI отсутствует, скачайте Rust-архив официального GitHub-релиза и проверьте checksum и attestation репозитория/workflow до запуска. Исторический Python-пакет не устанавливайте. `ai-stp state path` показывает каталог, `ai-stp init` явно создаёт новую локальную идентичность. Для старых Python-данных нужен `ai-stp state migrate plan`, а не второй аккаунт. Исследуйте только указанные пользователем проекты, не весь домашний каталог.
