# Managed installation components

Сетап-системы — компоненты ai-stp с отдельными репозиториями релизов. CLI сам их получает и проверяет; отдельный setup-manager не нужен. `ai-stp provider inspect` показывает точную поверхность, `ai-stp program status` наблюдает установленный харнесс. Pin провайдера не разрешает обновлять харнесс. Отказы проверки и изоляции не обходите.
