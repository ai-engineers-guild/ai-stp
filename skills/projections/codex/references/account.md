# Account, grants and sync

Use `ai-stp account status`, then `ai-stp account plan` and its exact apply operation. Reuse a pending browser code and honor next_poll_at; do not start fresh login repeatedly. If already signed in, do not initiate a replacement session without a task reason. Credentials never enter chat or plan files. Grants and visibility changes follow the user authority boundary. Private sync requires its explicit configuration and uses push/pull/merge/recover plans; account attachment and key recovery are separate operations.
