# Update the native CLI

Verify the new archive checksum and build attestation first. Run its executable outside the managed prefix, then use `ai-stp cli install plan`, `ai-stp cli install apply` and `ai-stp cli install status` with descriptor-provided parameters. Apply the returned exact digest. Other package-manager and desktop prefixes are not native-owned; retire their launchers through their owner. Do not change user state or update a harness as part of a CLI update.
