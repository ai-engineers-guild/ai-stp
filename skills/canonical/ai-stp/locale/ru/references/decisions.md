# Decisions

Задача пользователя — граница полномочий. Локальные обратимые шаги внутри этой
задачи идут без нового вопроса.

`mutability` и `confirmation` независимы. `confirmation: none` — не согласие.

- `read` — наблюдение.
- `plan` — точный предмет позже решения.
- `apply` — когда текущий запрос уже это разрешает.
- `destructive` — всегда отдельное решение непосредственно перед вызовом.

Отдельное решение пользователя нужно, когда: неразрешённый выбор меняет
результат; меняется видимость или доступ; создаётся линия основной версии;
привязываются учётные данные или аккаунт; данные, target или backup удаляются
без восстановления; выполняется незапрошенный Git или deploy; в композицию
входит объект `experimental` или с непроверенным автором.

Для `explicit_flag` получите решение, затем передайте параметр, который назвал
дескриптор. Для `plan_digest` выполните названную plan-команду, покажите эффект
и `required_authorization`, затем передайте digest, который вернул CLI. Не
считайте его сами. Устаревший план — новый план и новое решение, если эффект
изменился.

Проверки digest, предусловий и идемпотентности — механические, не вопросы.
