# Update the native CLI

Проверьте checksum и attestation нового архива. Запускайте его вне управляемого каталога; используйте `ai-stp cli install plan`, `ai-stp cli install apply` и `ai-stp cli install status`, передавая параметры из дескриптора и точный digest плана. Чужой package-manager/desktop prefix не перезаписывайте. Обновление CLI не меняет пользовательскую базу или харнесс.
