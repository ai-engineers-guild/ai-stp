# Configuration engines

`ai-stp capabilities --json` сообщает о нативной поддержке в
`native_configuration`. Новые сетапы применяет встроенный движок.
`ai-stp program status` показывает установленный харнесс.

Исторические операции внешних провайдеров сохраняют исходный проверенный
релиз, план и квитанцию. Используйте их исходный путь восстановления.
