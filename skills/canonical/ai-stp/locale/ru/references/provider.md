# Provider and toolchain

Намерения: установить провайдер, закрепить toolchain, установить программу
харнесса.

Берите из machine help: `ai-stp provider fetch`, `ai-stp provider trust`,
`ai-stp provider check`, `ai-stp provider conformance`,
`ai-stp provider update plan`, `ai-stp toolchain install`,
`ai-stp harness install`, `ai-stp harness status`.

Нужны и доверие к выпуску, и conformance. Подпись — не совместимость.
Проверяйте `ai-stp provider check` и `ai-stp harness status`.
