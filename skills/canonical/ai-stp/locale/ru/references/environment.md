# Environment

Намерения: настроить проект, подготовить несколько харнессов, установить
программы и инструменты, необходимые выбранным сетапам.

Берите из machine help: `ai-stp environment inspect`, `ai-stp environment plan`,
`ai-stp harness install`, `ai-stp harness status`, `ai-stp toolchain profile`,
`ai-stp toolchain install`, `ai-stp component program install`,
`ai-stp component program status`, `ai-stp install transaction approve`,
`ai-stp install transaction apply`, `ai-stp install transaction status`,
`ai-stp install transaction recover`.

Изучите проект и выберите точные версии сетапов. Каждый сетап принадлежит
своему харнессу. Проверьте их предпосылки и явно выбранные инструменты
toolchain. Выполните подходящие действия подготовки в рамках поручения,
затем повторите проверку. Наличие программы, авторизация и проверенная
нативная конфигурация — отдельные факты; отсутствие наблюдения не означает
готовность.

Составьте планы конфигураций и объедините точные дочерние планы. Разрешите
конфликты нативных путей до записи. Применяйте общий digest через координатор,
сохраните ID каждого прежнего сетапа. При сбое используйте восстановление
общей операции; не повторяйте её дочерние операции независимо.

Версии общих исполняемых программ отделены от нативного снимка харнесса.
Используйте точную требуемую версию. Возврат сетапа не разрешает удалять
общий инструмент или runtime другого проекта.
