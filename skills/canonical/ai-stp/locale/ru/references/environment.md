# Environment

Намерения: настроить проект, подготовить несколько харнессов, установить
программы и инструменты, необходимые выбранным сетапам.

Стартуйте intent `install` по одному сетапу на харнесс. Не набирайте
`environment plan`, `environment inspect`, `install transaction plan`,
`install transaction approve` или `install transaction apply`. Координация
нескольких корней — экспертное
восстановление: см. [recover](recover.md), если агрегат уже есть.

Intent `inspect` — только когда пользователь спросил, что не так. Каждый
сетап принадлежит своему харнессу. Наличие программы, авторизация и
проверенная нативная конфигурация — отдельные факты.

Версии общих исполняемых программ отделены от нативного снимка харнесса.
Возврат сетапа не разрешает удалять общий инструмент или runtime другого
проекта. Остальные листья toolchain и harness-program — в machine help.
