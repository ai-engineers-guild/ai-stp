# Self

Намерения: установить Skill ai-stp в харнесс, удалить его.

Берите из machine help: `ai-stp skill status`, `ai-stp skill install`,
`ai-stp skill remove`.

Назначение обязательно, пока нет discovery харнесса. Ставьте в каталог с именем
`ai-stp`, чтобы `name` пакета совпал. Этот Skill — control plane: установка,
обновление или удаление пользовательского сетапа не должны его удалять.

`foreign` значит, что файл написал кто-то другой; не перезаписывайте.
`stale` значит, что его правили после этой установки; удаляйте только по явной
просьбе. Никогда не удаляйте этот Skill как часть смены сетапа.
